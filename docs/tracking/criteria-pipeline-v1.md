### 잡아낸 결함 3개
1. **좌표계 오류** — 인허가를 EPSG:2097로 가정. 실제 **EPSG:5174**. 내부 검증 14/14가 통과하는 상태에서 전 점포가 100~200m(격자 1~2칸) 밀려 있었다. 역지오코딩 대조에서 91%만 일치, 불일치가 전부 인접 자치구로 밀린 패턴이라 발각.
2. **행정동 매핑 75.5%** — "포함 상권의 행정동" 휴리스틱이 4개 중 1개꼴로 인접 동을 붙였다. 역지오코딩 직접 조회로 교체(100%).
3. **역지오코딩 실패의 무음 처리** — 429 외 HTTP 에러를 "행정동 없음"으로 오분류. 실패 격자가 이전 휴리스틱 값을 유지해 정확한 값처럼 남았다. 비-200 전부 재시도로 수정, 미응답은 명시적 NULL.
