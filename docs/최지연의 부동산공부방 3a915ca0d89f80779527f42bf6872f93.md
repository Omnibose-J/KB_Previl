# 최지연의 부동산공부방

예상 매출 × 마진율 × 지속 확률 − 동급 상권 평균 = **데이터 기반 권리금 적정가**

++연계 상품 제안

### **1. KB 권리금 시세**

- **권리금 적정가 리포트** — 매물 검토 단계에서 "호가 8천, KB 추정 적정가 5,200" 제공

- **권리금 연계 신용대출** — 주의: 권리금은 법적으로 담보 설정이 어려워. "권리금 담보대출"이라고 쓰면 감점 위험. **"KB 적정가 검증을 통과한 권리금 거래에 한해 한도·금리 우대하는 신용대출"** 구조로 써야 정확함. 이 디테일을 아는 것 자체가 실무 감각으로 보임

### 2. 임대인 뒤집기 (메인 아님. 로드맵으로 빼버림)

- 임대인: 공실 해소, 임대수익 안정 → KB 담보대출 부실↓ (상가 담보대출의 리스크는 결국 공실이니까)
- 임차인: 검증된 자리 매물이 늘어남
- KB: **한 엔진으로 양면시장(임차인+임대인)을 다 먹음**

#### 2-1. 건물주에게 뭘 주는가 — 4가지

**① 테넌트믹스 추천**

"이 건물 1층 공실에 어떤 업종을 넣어야 하는가." 업종별 동적 가중치를 그대로 뒤집으면 나옴. 게다가 **건물 단위 시너지**까지 볼 수 있음 — 2층이 필라테스면 1층은 샐러드·주스가 유리하고, 지하가 술집이면 1층에 카페는 낮 장사만 됨. 이건 상권 데이터만으론 안 나오고, 건물 내 기존 임차인 구성을 알아야 나오는 정보임. 건물주만 줄 수 있는 데이터고, 우리 모델의 해상도를 한 단계 올려줌.

**② 공실 위험 조기경보**

현 임차인의 상권이 꺾이면 → "6개월 내 이탈 가능성 높음, 지금부터 후속 임차인 준비하세요." 공실 3개월을 0개월로 줄여주는 서비스. 

**③ 적정 임대료 산정**

"이 자리에서 카페가 낼 수 있는 최대 임대료는 월 430만원. 그 이상 받으면 임차인이 2년 내 버티기 어렵고, 결국 공실 리스크로 돌아옵니다." — **임대료 상한을 데이터로 제시하는 것**이 오히려 건물주에게 이득이라는 논리.

**④ 건물 가치 시뮬레이션**

상업용 부동산 가치는 수익환원법으로 매겨진다. 즉 **임대수익 ÷ 자본환원율 = 건물 가격.** 그러니까 "우량 임차인 유치 → 임대수익 안정 → 건물 감정가 상승"이 직접 연결됨. 건물주가 가장 반응할 숫자임.

#### 2-2. **여기서 나오는 KB 연계 상품 두 개:**

#### 🔹 테넌트 연동 상가담보대출

> "KB 검증 등급 A 이상의 임차인으로 채워진 건물은 담보 가치가 안정적이다 → 금리·LTV 우대"
> 

임차인 쪽에서 제안했던 '상권연동 금리'와 **완전히 같은 논리를 임대인 쪽에 적용**한 거임. 그래서 기획안에서 두 상품이 하나의 원칙으로 묶임: **"KB는 사람과 건물이 아니라, 자리와 조합을 평가한다."** 상품 두 개가 각각 노는 게 아니라 하나의 철학에서 파생되면 기획 완성도가 확 달라 보임.

#### 🔹 공실 리스크 관리 = 여신 사후관리

상가 담보대출이 부실 나는 경로가 뭐야? 공실 → 임대수익 감소 → 이자 못 냄. 즉 **KB는 이미 공실 위험에 노출돼 있는데, 그걸 감지할 수단이 없음.** 

임차인 쪽 '리로케이션 지원'과 대칭— **한쪽은 임차인이 망하기 전에 옮겨주고, 한쪽은 건물이 비기 전에 채워줌. 둘 다 KB 여신을 지키는 행동.**

↓

↓
예비창업자에게 "실제 계약 가능한 매물" 추천 가능
↓
매칭 성사 → 임차인: 창업대출 / 임대인: 공실 해소
↓
계약·생존 결과가 정답 데이터로 축적
↓
모델 정확도 ↑ → 양쪽 다 더 정확한 추천

## 1. "시세"라는 단어가 두 가지 뜻으로 쓰이고 있어

혼란의 원인이 이거야.

**뜻 A: 실제로 거래된 가격들의 평균**
"이 아파트 지난달에 12억에 팔렸대" → 그러니까 시세 12억. **과거 거래 기록의 요약**이야.

**뜻 B: 이 자산이 받아야 마땅한 값**
"이 가게는 이 정도 버니까 이 정도 값어치다" → **자산의 수익력에서 역산한 값**이야.

내가 말한 건 **B**야. A는 애초에 불가능해 — 권리금 실거래 기록이 세상에 없으니까. 근데 B는 거래 기록이 하나도 없어도 계산돼. **자산이 얼마 버는지만 알면 되거든.**

---

## 2. 두 방식의 차이 — 감정평가의 기본

부동산·자산 가치를 매기는 방법은 크게 둘이야:

|  | 거래사례비교법 | 수익환원법 |
| --- | --- | --- |
| 질문 | "비슷한 게 얼마에 팔렸나?" | "이게 얼마를 벌어주나?" |
| 필요한 것 | **과거 실거래 데이터** | **미래 수익 예측** |
| 쓰이는 곳 | 아파트, 중고차 | 빌딩, 기업, 상가 |
| 권리금에 적용 | ❌ 데이터 없어서 불가 | ⭕ 가능 |

주식으로 비유하면 확 와닿아. 비상장 기업 주식은 거래가 없어서 "얼마에 팔렸나"를 알 수 없잖아. 그래도 가치평가는 해. **"이 회사가 앞으로 얼마 벌지"를 계산해서 현재가치로 환산**하지. DCF가 그거고, 이게 수익환원법이야.

권리금도 똑같아. **권리금은 "이 자리가 앞으로 벌어다 줄 초과수익을 미리 사는 값"**이니까, 미래 수익을 예측할 수 있으면 값이 나와. 그리고 TEO는 이미 그걸 예측하고 있어. **매출 예측 모델을 가진 순간, 권리금 계산기는 공짜로 딸려오는 거야.**

---

## 3. 실제로 계산해보면 이런 식

성수동 A매물, 브런치 카페, 호가 권리금 8,000만원이라고 치자.

**[1단계] 이 자리가 얼마 버나 — TEO 출력**

```
예상 월매출              1,900만원
영업이익률 15%    →  월 영업이익 285만원
```

**[2단계] 그중 "이 자리라서" 더 버는 건 얼마인가**

```
동급 상권 같은 업종 평균 월매출   1,400만원
                    평균 영업이익   210만원

초과수익 = 285 − 210 = 월 75만원 (연 900만원)
```

⚠️ **여기가 핵심이야.** 권리금은 "이 가게가 버는 돈 전부"에 대한 값이 아니야. 아무 데나 열어도 벌 수 있는 평균치는 빼야 해. **평균보다 더 버는 부분, 그게 자리의 값이야.** 평균만큼밖에 못 버는 자리면 권리금은 0원이 나와야 정상이고.

**[3단계] 그게 몇 년이나 갈까**

```
3년 생존확률 62%  →  기대 존속기간 약 3년
연 900만원 × 3년 = 2,700만원  (할인율 적용 시 더 낮아짐)
```

→ **무형 권리금(바닥+영업) ≈ 2,700만원**

**[4단계] 설비는 따로**

```
인테리어·주방설비 취득가 5,000만원, 2년 경과 감가 → 잔존 2,500만원
```

→ **시설권리금 ≈ 2,500만원**

**[결과]**

```
호가          8,000만원
KB 추정가     5,200만원  (2,700 + 2,500)
              ─────────
협상 여지     2,800만원
```

**실거래 데이터를 단 한 건도 안 쓰고 숫자가 나왔지.** 이게 "거래 기록 없이 시세를 만든다"는 말의 실제 의미야.

## 4. 그럼 이게 진짜 "시세"가 맞아?

**엄밀히 말하면 아직 아니야.** 이건 **추정가**지 시세가 아니야. 시세라는 말은 시장이 실제로 그 가격에 거래할 때 성립하는 거니까.

그래서 2단계로 가야 해. 여기가 지난번에 내가 말한 부분인데, 이해가 안 됐다면 아마 이 두 단계가 뭉쳐서 들렸을 거야:

```
[1단계] 추정가를 뿌린다
  모델로 계산한 참고지표. 아직 시세 아님.
  "협상할 때 참고하세요" 수준.
        ↓
  사람들이 이 숫자를 보고 협상하기 시작
        ↓
[2단계] 에스크로로 실제 거래를 태운다
  KB 계좌로 권리금이 오가면 → 실제 거래액이 기록됨
  ★ 여기서 세상에 없던 실거래 데이터가 처음 생김 ★
        ↓
[3단계] 추정가 vs 실거래가를 비교해 모델 보정
        ↓
[4단계] 이제 진짜 "KB 권리금 시세"
  거래사례비교법도 가능해짐 → 여신 심사에 쓸 수 있는 수준
```

즉 **추정가는 시세를 만들기 위한 씨앗**이야. 처음부터 시세를 선언하는 게 아니라, 추정가로 시장을 움직여서 실거래를 모으고, 그걸로 진짜 시세를 완성하는 순서.

**KB시세가 실제로 밟은 경로가 이거야.** 국민은행이 주택담보대출을 하면서 감정·거래 정보가 쌓였고, 그게 시세가 됐어. **시세가 먼저 있어서 대출을 한 게 아니라, 대출을 하니까 시세가 생긴 거야.** 그래서 "KB시세가 아파트에서 한 일을 점포에서 반복한다"는 게 그냥 멋진 말이 아니라 **똑같은 순서를 밟는다**는 뜻이야.

## 5. 정직하게 — 이 방식의 약점

발표에서 찔릴 부분이니까 미리 알고 있어야 해. 위 계산에 **가정이 네 개** 들어갔어:

| 가정 | 어떻게 방어하나 |
| --- | --- |
| 영업이익률 15% | 업종별 통계 기반. 소상공인실태조사 영업이익률 사용 |
| "동급 상권" 정의 | 임대료 구간 + 유동인구 규모로 군집화 (K-means 등) |
| 기대 존속기간 3년 | 생존확률 모델 출력 그대로 사용 |
| 할인율 | 소상공인 대출 금리 수준으로 설정 |

가정이 많다는 건 사실 약점이야. 근데 **이걸 숨기지 말고 서비스 화면에 그대로 드러내는 게 방어책**이야:

> "저희는 정답을 주는 게 아니라, **계산 과정을 공개**합니다. 지금 권리금은 근거 없이 8,000만원이 불리는데, 저희는 왜 5,200만원인지 네 개의 가정과 함께 보여줍니다. **틀릴 수는 있지만, 검증 가능합니다.** 검증 불가능한 호가와 검증 가능한 추정 중 어느 쪽이 시장에 필요한지가 저희 주장입니다."
> 

그리고 다시 강조하는데 — **"감정가"라는 단어는 절대 쓰지 마.** 감정평가는 자격 있는 사람만 할 수 있어. "추정 참고가", "협상 참고지표"로 통일해.

## 한 줄 정리

> **거래 기록이 없어도 값은 매길 수 있다. "얼마에 팔렸나" 대신 "얼마를 벌어주나"로 계산하면 되니까.**
TEO는 이미 매출을 예측하고 있으니, 그 능력이 그대로 권리금 계산기가 된다.
그렇게 만든 추정가로 거래를 모으면, **그때 비로소 진짜 시세가 생긴다.**
> 

---

여기까지가 이해되면 다음은 "동급 상권을 어떻게 정의할 것인가"가 실제 구현의 관건이야. 이건 예전에 K-means 써봤던 방식이 그대로 들어맞는 부분이라, 필요하면 그 군집화 설계부터 잡아줄게.

### 점포 승계 거래소, 권리금 연계 대출, 에스크 셋 다 빼버림 → 새 로직 설계(클로드 채팅 그대로 보셈)

빼기로 한 셋은 전부 **거래에 개입하는 기능**이었어. 리포트는 **판단을 돕는 기능**이고, 이건 성격이 달라. 남의 거래에 끼어들지 않고 정보만 주는 거니까 중개·자금 규제에서 자유롭고, 도의적으로도 깔끔해. 실제로 증권사 리서치가 정확히 그 포지션이잖아 — 주식을 대신 사주지 않고 분석만 하지.

다만 하나 짚고 갈게. **승계 거래소를 뺀 이유가 "상권 하락을 감지해 알리는 게 도의적으로 걸린다"면, B-1 리로케이션도 같은 구조야.** 기존 사장님에게 "여기 꺾입니다"라고 알리는 건 동일하거든. 팀에서 이것도 뺄지 의식적으로 정해두는 게 좋아. (개인적으로는 B-1은 **KB 자기 차주에게 도움을 먼저 제안하는 것**이라 성격이 다르다고 보지만, 판단은 너희 몫이야.)

그리고 리포트만 남기면 **타깃이 예비창업자 하나로 깔끔하게 정리돼.** 기획 산만함 문제도 같이 해결되는 거야.

# 1. 적정 권리금 산출 로직

## 대전제 — 법이 정한 3분할을 그대로 따른다

상가건물임대차보호법 제10조의3은 권리금을 "영업시설·비품, 거래처, 신용, 영업상의 노하우, 상가건물의 위치에 따른 영업상의 이점 등 유형·무형의 재산적 가치의 양도 대가"로 정의해.

**법 조문 자체가 유형/무형을 나누고 있어.** 우리 산식도 여기 맞춰:

```
적정 권리금 = 무형재산 가치 + 유형재산 가치
              (수익환원법)      (원가법)
```

이건 우리가 만든 게 아니라 감정평가 실무기준의 원칙과 같은 구조야. 제10조의7이 국토부장관에게 권리금 감정평가 기준 고시 권한을 주고 있으니 **"공적 평가 기준을 데이터로 자동화했다"**는 프레이밍이 성립해. (조문·고시 최신 내용은 직접 확인해서 인용해.)

---

## Part A. 무형재산 — 초과수익 자본화

### Step 1. 이 자리가 얼마 버나

TEO 출력을 그대로 씀.

```
예상 월매출 (M)                = 1,900만원
업종 영업이익률 (r)            = 15%    ← 소상공인실태조사 업종별
월 영업이익 = M × r            = 285만원
```

### Step 2. "이 자리라서" 더 버는 부분만 분리 ★핵심

```
동급 상권·동일업종 평균 월매출  = 1,400만원
평균 월 영업이익               = 210만원

월 초과수익 (E) = 285 − 210    = 75만원
연 초과수익                    = 900만원
```

**여기가 이 모델의 심장이야.** 권리금은 "이 가게가 버는 돈"에 대한 값이 아니라 **"아무 데나 열었을 때보다 더 버는 부분"**에 대한 값이거든. 평균만큼밖에 못 버는 자리는 **권리금 0원**이 나와야 정상이고, 실제로 그렇게 나와. 이게 "거품을 걷어낸다"는 주장의 근거야.

> **"동급 상권"을 어떻게 정의하느냐가 모델 전체의 신뢰도를 좌우해.** 임대료 수준 + 유동인구 규모 + 배후인구 구성으로 서울 상권을 군집화(K-means)하고, 같은 군집 내 동일업종 평균을 벤치마크로 씀. 이 부분은 클러스터링 결과를 시각화해서 부록에 넣으면 방법론 신뢰도가 확 올라가.
> 

### Step 3. 그게 몇 년이나 가나

```
존속기간 (N) = min(생존확률 기반 기대존속기간, 임대차 잔여 보장기간)
```

두 개 중 **짧은 쪽**을 써야 해. 3년 더 벌 수 있어도 임대차가 2년 뒤 끝나면 2년치만 값어치가 있으니까. 상가임대차법상 갱신요구권 보장기간과 현 계약 잔여기간을 같이 봐야 함. **이 조건을 넣는 것 자체가 실무 이해도로 읽혀.**

### Step 4. 현재가치로 환산

```
                N     E × 12
무형재산 가치 =  Σ  ──────────
               t=1   (1 + d)^t

d = 할인율 (소상공인 대출금리 + 사업위험 프리미엄)
```

```
E = 900만원/년, N = 3년, d = 8%
→ 무형재산 ≈ 2,320만원
```

⚠️ 지난번 계산에서 900×3=2,700으로 단순 합산했는데, **할인율을 적용하면 2,320만원**이야. 리포트에서는 반드시 할인 적용한 값을 써. 안 그러면 "DCF를 흉내만 냈다"는 지적을 받아.

---

## Part B. 유형재산 — 원가법

```
유형재산 가치 = 재조달원가 × 잔가율
```

```
인테리어 재조달원가   4,000만원 × 잔가율 40% (2년 경과) = 1,600만원
주방설비 재조달원가   2,500만원 × 잔가율 45%           = 1,125만원
─────────────────────────────────────────────
유형재산 합계                                        ≈ 2,725만원
```

**재조달원가 출처가 중요해.** 여기가 데이터 확보의 관건인데:

- **가맹사업거래정보시스템 정보공개서** — 브랜드별 평당 인테리어 표준단가가 법정 공시 항목이라 가장 신뢰도 높음
- 업종별 내용연수 적용해 감가 (인테리어는 통상 5년 내외로 보지만, 세법상 내용연수 기준을 확인해서 근거를 달아)

---

## Part C. 조정계수

기계적 합산으로 끝내면 안 돼. 현실 변수를 반영하는 층이 하나 더 필요해:

| 조정 항목 | 방향 | 근거 |
| --- | --- | --- |
| 임대차 잔여기간 짧음 | (−) | 회수 기간 부족 |
| 임대료 인상 예정 | (−) | 초과수익 잠식 |
| 상권 모멘텀 상승 (비정형 지표) | (+) | 미래 초과수익 증가 기대 |
| 동일업종 경쟁 밀도 상위 | (−) | 초과수익 지속성 위협 |
| 프랜차이즈 신규출점 인접 | (−) | 대체 위협 |

**비정형 데이터가 여기서 들어와.** SNS·검색량 모멘텀이 최종 숫자에 어떻게 반영되는지 경로가 명확해야, "비정형 쓴다면서 어디에 쓰냐"는 질문을 막을 수 있어.

```
┌────────────────────────────────────────────┐
│  적정 권리금                                │
│                                             │
│   = Σ [(예상영업이익 − 동급평균영업이익)     │
│         ÷ (1+할인율)^t]        ← 무형        │

```

```

─────────────────────────────
KB 추정 적정가  ≈ 5,200만원
호가            = 8,000만원
괴리율          = +54% (과지불 구간)
```

## 이 포맷이 강한 이유 3가지

**① 민감도 분석이 방어막이야**
지난번에 "가정이 많다"는 게 약점이라고 했잖아. 증권사 리포트는 그걸 **테이블로 공개**해서 해결해. 단일 숫자가 아니라 밴드로 제시하면 "5,200이 왜 정확하냐"는 공격이 무력화돼. **"정확한 답을 주는 게 아니라 합리적 범위를 준다"**로 포지션이 바뀌거든.

**② 근거 공개가 신뢰의 원천**
증권 리서치의 문화가 뭐야? 목표주가와 **산출 근거를 다 공개**하고, 틀리면 수정 리포트를 내는 것. 이 문화를 그대로 가져오면:

> "지금 권리금 8,000만원에는 아무 근거가 없습니다. 저희 5,200만원에는 여섯 개의 근거와 세 개의 가정이 붙어 있습니다. **틀릴 수 있지만 검증할 수 있습니다.**"
> 

**③ 하단 고지가 법적 방어선**
증권사 리포트 맨 아래 컴플라이언스 문구 있잖아. 똑같이 넣어. **"감정평가가 아니다"를 문서에 박아두는 것**이 지난번에 말한 감정평가법 리스크 대응이야. 발표에서 이 문구를 짚으면서 "저희는 법정 평가를 대체하지 않습니다"라고 먼저 말하면, 지적당하기 전에 방어가 끝나.

## 하나 더 — 이력 관리가 진짜 무기

증권 리서치가 신뢰받는 이유는 **적중률이 추적되기 때문**이야. 이걸 흉내 내면:

> 발행한 리포트의 추정 매출 vs 실제(공공 추정매출 갱신 시) 비교 → **모델 적중률 공개**
> 

기획안에 "리포트 발행 후 4분기 시점에 추정치를 사후검증하고 정확도를 공시한다"고 쓰면, §7 로드맵의 Phase 5(사후검증)와도 자연스럽게 연결돼. **"우리는 틀린 걸 숨기지 않는다"**는 태도가 데이터 서비스 기획에서 가장 세련된 포인트야.

## 0. 시작 전 반드시 합의할 것 — "학습"과 "계산"의 구분

이 파이프라인에서 **머신러닝으로 학습되는 것은 3개뿐**이고, 권리금 산식 자체는 학습 대상이 아니다.
이 구분을 흐리면 "권리금을 AI가 예측한다"는 잘못된 설명이 되고, 심사에서 "정답 데이터도 없는데
어떻게 학습하냐"는 질문에 무너진다.

| 구분 | 대상 | 방식 | 정답(label) |
| --- | --- | --- | --- |
| **학습됨** | ① 동급 상권 군집 | 비지도 (K-means/GMM) | 없음 |
| **학습됨** | ② 예상 매출 | 지도학습 회귀 (LightGBM) | 서울시 추정매출 |
| **학습됨** | ③ 기대 존속기간 | 생존분석 (Cox / KM) | 점포 폐업 이벤트 |
| **계산됨** | ④ 권리금 적정가 | 결정론적 산식 (DCF + 원가법) | — |

> **발표용 문장:**
"권리금 자체를 예측하는 모델이 아닙니다. 권리금은 법이 정한 평가 원칙에 따라 **계산**됩니다.
저희가 학습시키는 것은 그 계산에 들어가는 **입력값**입니다."
>

```
│  → M         │ │  → N         │ │  → V_tan     │
└──────────────┘ └──────────────┘ └──────────────┘
          │              │              │
          └──────────────┴──────────────┘
                         ▼
          ┌─────────────────────────────┐
          │ E 조정계수  (규칙 기반)       │
          │ F 밸류에이션 결합 + 밴드 산출 │
          └─────────────────────────────┘
                         ▼
                  [리포트 생성 (LLM)]
```

## 3. Module A — 동급 상권 군집화

### 3.1 왜 필요한가

권리금의 무형재산 가치는 **"평균적인 자리보다 얼마나 더 버는가(초과수익)"** 로 정의된다.
따라서 "평균적인 자리"의 기준선, 즉 **벤치마크 집단**을 정의하는 것이 이 모델의 출발점이다.
군집이 잘못되면 초과수익이 통째로 틀리고, 권리금 추정가 전체가 무너진다.

### 3.2 ★ 가장 중요한 설계 원칙 — 순환논리 함정

> **군집 변수에 매출(`sales_est`)을 절대 넣지 마라.**
> 

매출로 군집화하면 같은 군집 = 매출이 비슷한 상권이 된다.
그러면 `초과수익 = 해당 상권 매출 − 동급 평균 매출 ≈ 0` 이 되어,
**모든 상권의 무형 권리금이 0에 수렴한다.** 모델이 아무것도 말하지 못하게 된다.

**올바른 설계:**

- 군집화 변수 = **상권의 구조·체급을 나타내는 변수만** (유동인구, 배후인구, 접근성, 밀도, 구성)
- 매출은 군집화가 **끝난 뒤에** 각 군집의 벤치마크를 계산할 때만 사용

```
[구조 변수로 군집] → [군집이 정해짐] → [군집 안에서 매출 평균 산출] → [초과수익 계산]
     매출 미사용                            여기서 매출 첫 등장
```

이 순서를 지켜야 "구조적으로 비슷한 상권들인데, 이 자리만 유독 더 번다"는 문장이 성립한다.
**그게 곧 권리금의 정의다.**

### 3.3 임대료 변수 — 조건부 포함

`rent_per_sqm`은 애매하다. 상권의 체급을 잘 나타내지만, 임대료는 매출의 함수이기도 해서
약한 순환논리가 있다.

**권고: 두 버전을 만들어 비교한다.**

- Model A1: 임대료 포함
- Model A2: 임대료 제외

두 버전의 군집 결과가 크게 다르지 않으면 임대료를 포함(해석력이 좋아짐).
크게 갈리면 제외하고, 임대료는 **조정계수(Module E)에서만** 반영한다.
이 비교 실험 자체를 부록에 넣으면 방법론 신뢰도가 올라간다.

### 3.4 전처리

1. **분기 평균화** — 최근 4~8분기 평균으로 노이즈 제거 (단일 분기 사용 금지)
2. **로그 변환** — 유동인구·점포수·상주인구는 멱함수 분포. `log1p` 적용
3. **비율 변수** — 연령·시간대·요일은 절대값이 아니라 **구성비**로 변환
(규모는 총계 변수가 이미 담당. 중복 방지)
4. **표준화** — `StandardScaler`
5. **다중공선성 점검** — VIF > 10 변수 제거, 또는 PCA로 누적기여율 85%까지 축소
6. **이상치** — 관광특구(명동 등)는 구조가 극단적이라 K-means 중심을 왜곡한다.
사전 분리하거나 HDBSCAN으로 outlier 처리

### 3.5 알고리즘 선택

| 알고리즘 | 장점 | 단점 | 권고 |
| --- | --- | --- | --- |
| **K-means** | 빠름, 해석 쉬움, 설명 편함 | 구형 군집 가정, 경계 상권 강제 배정 | **1순위 (기본)** |
| **GMM** | soft assignment, 경계 상권에 확률 부여 | 해석 복잡 | 실루엣 낮을 때 대안 |
| **Ward 계층군집** | 덴드로그램으로 위계 설명 가능 | 대규모 느림 | 발표 시각화용 병행 |
| **HDBSCAN** | 이상치 자동 분리 | 군집 수 통제 불가 | 이상치 탐지용 보조 |

**실무 권고:** K-means를 메인으로 하고, GMM의 소속 확률을 **벤치마크 가중평균**에
쓰면 경계 상권 문제를 우아하게 푼다 (3.8 참고).

### 3.6 k 결정

세 가지를 모두 보고 결정한다. 하나만 보면 안 된다.

1. **Elbow** — inertia 감소율 꺾이는 지점
2. **Silhouette Score** — 0.25 이상이면 수용 가능 (사회과학 데이터는 0.5 넘기 어렵다)
3. **해석 가능성** — 각 군집에 실무적 이름을 붙일 수 있는가

**권장 범위: k = 6 ~ 8.**
너무 적으면 벤치마크가 뭉개지고, 너무 많으면 군집당 표본이 부족해 평균이 불안정해진다.

### 3.7 군집 네이밍 (예시 — 실제 결과로 대체할 것)

| 군집 | 특징 | 예상 해당 |
| --- | --- | --- |
| C1 광역 상업중심 | 유동 최상위, 임대료 최상위, 업종 다양성 높음 | 강남역, 홍대 |
| C2 오피스 배후 | 직장인구 압도적, 주중·점심 편중 | 여의도, 을지로 |
| C3 신흥 트렌드 | 2030 비율 높음, 점포 회전 빠름, 모멘텀 상위 | 성수, 연남 |
| C4 대학가 | 20대 편중, 저가 업종 밀집 | 신촌, 회기 |
| C5 주거 밀착 골목 | 상주인구 중심, 주말·저녁 유동 | 일반 골목상권 |
| C6 교통 결절 | 지하철 환승 인접, 통과 유동 | 사당, 왕십리 |
| C7 관광 특화 | 외지 유입, 계절성 큼 | 명동, 인사동 |

**군집에 이름을 붙이는 작업은 형식이 아니라 검증이다.**
이름이 안 붙는 군집이 나오면 변수 선정이 잘못된 것이다.

### 3.8 벤치마크 산출 — 계층적 폴백 규칙

군집만으로는 부족하다. 벤치마크는 **(군집 × 업종)** 셀 단위여야 한다.
그런데 셀에 점포가 몇 개 없는 경우가 반드시 생긴다. 폴백 규칙을 미리 정해둔다.

```
Level 1: 동일 군집 × 동일 업종 소분류      (n ≥ 30)  ← 최우선
Level 2: 동일 군집 × 동일 업종 중분류      (n ≥ 30)
Level 3: 인접 군집 통합 × 동일 업종 중분류 (n ≥ 30)
Level 4: 서울 전체 × 동일 업종 중분류      (최후)
```

- 각 리포트에 **어느 레벨의 벤치마크가 사용됐는지 표기**한다.
Level 3~4가 쓰였으면 "표본 부족으로 신뢰도 낮음" 경고를 띄운다.
이게 곧 콜드스타트 대응이고, 정직성의 근거가 된다.
- 벤치마크 대표값은 **평균이 아니라 중앙값**을 권장한다. 상권 매출은 우측 꼬리가 길다.
- GMM을 쓰는 경우: 소속 확률을 가중치로 여러 군집 벤치마크를 가중평균

### 3.9 군집 검증

| 검증 | 방법 | 합격선 |
| --- | --- | --- |
| 응집도 | Silhouette | ≥ 0.25 |
| **설명력 (핵심)** | 군집 변수에 매출을 안 넣었는데도, 군집이 업종별 매출 분산을 얼마나 설명하는가 (ANOVA η²) | η² ≥ 0.2 |
| 안정성 | Bootstrap 80% 재표본 20회 → ARI | ARI ≥ 0.6 |
| 시간 안정성 | 2023년 데이터 군집 vs 2025년 군집 ARI | ARI ≥ 0.5 |

> **설명력 검증이 이 모델의 승부처다.**
매출을 안 쓰고 만든 군집이 매출을 잘 설명한다면,
"상권 구조가 매출을 결정한다"는 우리 가설이 데이터로 증명된 것이다.
**이 수치 하나가 발표에서 가장 강한 슬라이드가 된다.**

## 4. Module B — 예상 매출 예측 (M)

| 항목 | 설계 |
| --- | --- |
| 예측 단위 | 상권 × 업종 소분류 × 분기 |
| 타깃 y | `log(분기 추정매출 / 점포수)` = 점포당 월평균 매출 로그 |
| 모델 | LightGBM Regressor |
| 검증 | **시계열 분할** (t 이전 학습 → t+1~t+4 예측). 랜덤 split 금지 |
| 지표 | MAPE, RMSLE, 그리고 **랭킹 상관(Spearman)** |

**피처 그룹**

1. 구조: Module A 군집 변수 전체 + `cluster_id` (categorical)
2. 경쟁: 동일업종 점포 밀도, 최근 4분기 순증감
3. 시차: 자기 상권 매출 t-1 ~ t-4 (있으면 강력)
4. **비정형 모멘텀**: 네이버 검색량 증가율, 지도 리뷰 수 증가율, 블로그 포스팅 증가율
5. 계절: 분기 더미

**★ 비정형 선행성 검증을 반드시 별도 실험으로 돌릴 것.**`교차상관(cross-correlation)`으로 "검색량이 매출을 몇 분기 선행하는가"를 측정하고,
그 lag를 피처에 반영한다. "검색량은 매출을 평균 2분기 선행한다" 같은 문장 하나가
비정형 데이터를 쓴 이유 전체를 정당화한다.

**⚠️ 한계 명시:** 서울시 추정매출은 **상권 단위 집계값**이지 개별 점포 매출이 아니다.
개별 매물로 내리려면 면적·층수·노출도 보정이 필요한데, 이는 공공데이터로 불가능하다.
→ 리포트에는 **"동일 상권·업종 점포당 평균 기준"** 이라고 명시하고,
개별 매물 정밀도는 KB 실매출 데이터 확보 이후 과제로 분리한다.

## 6. Module D — 유형재산 (V_tan)

```
V_tan = Σ (재조달원가_i × 잔가율_i)
잔가율 = max(0, 1 − 경과연수 / 내용연수)
```

| 자산 | 재조달원가 출처 | 내용연수(참고) |
| --- | --- | --- |
| 인테리어 | 가맹사업거래정보시스템 정보공개서의 **평당 표준 인테리어 단가** × 면적 | 5년 내외 |
| 주방설비 | 정보공개서 설비 항목 / 중고 시세 크롤링 | 5~8년 |
| 간판·사인 | 정보공개서 | 3~5년 |
- 정보공개서는 **법정 공시 항목**이라 신뢰도가 높다. 이 출처를 쓰는 것 자체가 강점이다.
- 내용연수는 세법 기준을 확인해 근거를 달 것. 임의 설정 금지.
- 실사 사진이 있으면 상태등급(상/중/하)으로 ±15% 조정.

| 경쟁 밀도 | 0.90 ~ 1.05 | 동일업종 밀도 백분위 |
| 대체 위협 | 0.92 ~ 1.00 | 인접 프랜차이즈 신규출점 |

```
adj = clip(Π 계수_i, 0.75, 1.25)
```

전체 조정폭을 ±25%로 캡한다. 조정계수가 본체를 압도하면 모델이 아니라 튜닝이 된다.

---

## 8. Module F — 최종 결합

```
① 월 영업이익      π = M × r            (r: 업종 영업이익률, 소상공인실태조사)
② 벤치마크 영업이익 π̄ = M̄ × r           (M̄: 동급 상권 벤치마크 매출)
③ 월 초과수익      E = π − π̄
④ 무형재산
                    N    E × 12
        V_intan =   Σ  ───────────
                   t=1   (1+d)^t
⑤ 유형재산         V_tan  (Module D)
⑥ 적정가          P = (V_intan + V_tan) × adj
```

**반드시 넣어야 할 처리 3가지**

1. **음수 절사**: `V_intan = max(0, V_intan)`
초과수익이 음수면 권리금은 0원이다. "이 자리는 권리금을 낼 이유가 없습니다"가
나올 수 있어야 모델이 정직해진다. **이게 거품을 걷어낸다는 주장의 실체다.**
2. **할인율 d**: 소상공인 대출금리 + 사업위험 프리미엄. 근거를 명시하고 고정.
3. **밴드 산출**: 단일 숫자로 내지 말 것.
    - 방법 1 (권장): 파라미터 민감도 그리드 — `r ± 3%p`, `N ± 1년`, `d ± 2%p` 조합의 5~95 백분위
    - 방법 2: LightGBM Quantile Regression으로 매출 예측구간 → 전파

## 9. 리포트 생성

**역할 분리를 지킨다.** 숫자는 전부 위 모듈에서 나오고, LLM은 **설명만** 한다.

```
[모듈 출력 JSON] → 템플릿 슬롯 채우기 → LLM은 요약·리스크 문장만 생성
```

LLM에게 숫자를 계산시키면 안 된다. 환각이 바로 신뢰 붕괴로 이어진다.
LLM 프롬프트에는 계산 결과와 SHAP 상위 기여 변수만 넘기고,
"이 값들을 근거로 3문장 요약을 쓰라"고 지시한다.

**리포트 필수 구성** (증권사 리서치 포맷 차용)

1. 협상 참고등급 / 호가 / 추정가 / 괴리율 / **추정 밴드**
2. 요약 3문장
3. 수익 추정 테이블
4. Valuation 내역 (무형/유형/조정 분해)
5. **민감도 분석 표** ← 가정이 많다는 약점을 정면으로 방어하는 장치
6. 강점 / 리스크
7. 산정 근거 데이터 출처 + **벤치마크 레벨 표기**
8. 하단 고지 — "본 자료는 공개 데이터 기반 참고용 추정치이며 감정평가법에 따른 감정평가가 아님"

> **용어 금지어**: "감정가", "투자의견", "권리금 담보". 각각 감정평가법·자본시장법·담보 설정 이슈.
→ "추정 참고가", "협상 참고등급", (대출 관련 언급 제외)
>

## 10. 검증 계획 (발표에서 점수가 나오는 부분)

| # | 실험 | 산출물 |
| --- | --- | --- |
| 1 | 군집 설명력 (매출 미사용 군집이 매출 분산을 설명하는가) | η², 실루엣 |

"틀린 걸 숨기지 않고 정확도를 공시한다"는 태도가 데이터 서비스 기획에서 가장 세련된 지점이다.

## 11. 정직하게 밝힐 한계

1. **개별 매물 정밀도의 한계** — 공공 추정매출은 상권 집계값. 점포 단위 보정 불가.
2. **권리금 실거래 데이터 부재** — 모델을 실제 권리금과 대조 검증할 방법이 현재 없다.
→ 거래사례비교법이 아닌 **수익환원 접근**을 택한 이유이자, 동시에 검증의 공백.
이 공백은 숨기지 말고 "그래서 지금까지 아무도 못 만들었다 = 선점 가치"로 프레이밍.
3. **상관 ≠ 인과** — 유동인구·검색량이 매출과 상관이 있어도 인과는 아니다. "참고지표" 포지션 유지.
4. **콜드스타트** — 비정형 데이터가 적은 신흥·주거지 상권은 신뢰도 하락. 벤치마크 레벨 표기로 대응.
5. **가정 의존성** — 영업이익률·내용연수·할인율은 외부 통계에서 가져온 가정값.
민감도 분석으로 공개 대응.
