작성 2026-07-26 · 범위: 서울 전역(1차) → 수도권(2차) · **업종: 요식업 한정** · 담당: 기술(데이터 소싱 · 실현가능성)

## 요약 — 결론 먼저

1. **핵심 4종은 전부 살아있고 키도 있다.** 소상공인 상가정보 · 서울 상권분석 · 서울 생활인구 · **서울 일반음식점 인허가 이력**. 추가 발급 없이 오늘 파이프라인을 시작할 수 있다.
2. **폐업 라벨이 실제로 만들어진다.** 서울 일반음식점 인허가 53.5만 건 중 약 80%가 폐업 이력. 10만 건 표본으로 **연도별 개업 코호트 생존율**을 계산했고 수치가 나왔다 (§3). 추천 로직을 사후검증할 수 있다는 뜻이며, 이게 이 프로젝트에서 가장 중요한 확인이다.
3. **공간해상도의 벽은 "매출"이다.** 점포 위치는 필지·층까지 특정되지만, 매출·유동인구는 상권 단위(등가반경 중앙값 151m)이고 **서울 면적의 27.2%, 음식점의 57.6%만** 덮는다. 나머지 42.4%는 매출 데이터가 없다.
4. **막힌 것은 3개**: SGIS 키 없음, VWORLD 데이터API 미승인, 부동산원 임대료 API 미승인. 전부 신청으로 풀리며 핵심 경로를 막지 않는다.

## 3. 폐업 라벨 검증 — 이 프로젝트의 근거

표본 10만 건으로 **개업 연도별 코호트 생존율**을 계산했다. 서울 일반음식점.

| 개업연도 | 개업수 | 1년 | 2년 | 3년 | 5년 |
|---|---|---|---|---|---|
| 2010 | 2,180 | 88.0% | 77.1% | 68.5% | 55.6% |
| 2013 | 1,894 | 91.0% | 80.7% | 70.0% | 54.8% |
| 2016 | 2,103 | 89.3% | 76.6% | 66.1% | 52.8% |
| 2019 | 2,442 | 86.9% | 73.1% | 62.9% | 46.8% |
| 2021 | 2,528 | 85.9% | 69.8% | 58.0% | 41.9% |
| 2023 | 2,567 | 80.3% | 65.3% | 55.0% | — |
| 2025 | 2,339 | 73.1% | — | — | — |

**읽히는 것**: 서울에서 문을 연 음식점의 3년 생존율이 2013년 개업 70.0% → 2023년 개업 55.0%로 내려앉았다. 5년 생존율은 2007년 56.6% → 2021년 41.9%다. 악화가 단조롭고 일관된다.

**계산 정의 (혼동 금지)**: `생존율 = 1 − (인허가일로부터 N년 내 폐업한 수) ÷ (해당 연도 개업 수)`. 이것은 "폐업한 가게 중 N년 못 버틴 비율"과 **전혀 다른 값**이다. 후자는 생존편향이 걸려 아무 의미가 없는데 자주 혼동된다.

**정직하게 붙여야 할 단서 세 가지**
1. **우편절단**: 2025년 12월 개업은 아직 1년이 지나지 않아 "1년 내 폐업" 판정이 불가능하다. 따라서 최근 1~2개 코호트의 생존율은 **실제보다 높게** 나온다. 그럼에도 73.1%까지 떨어졌다는 건 실제 악화가 표보다 더 심하다는 뜻이다
2. **폐업신고 지연**: 최근 코호트일수록 같은 방향으로 과대추정된다
3. **표본**: 전체 53.5만 중 10만(18.7%)을 랜덤 페이지 추출. 본 파이프라인에서는 전량으로 재계산할 것

**양도양수 문제 (미해결)**: 명의변경이 "폐업 + 신규개업"으로 기록되면 실제로는 계속 영업 중인 자리가 폐업으로 잡힌다. 같은 좌표·같은 업태에서 폐업일과 인허가일이 맞물리는 연속 레코드를 승계 후보로 분리해야 한다. **아직 처리하지 않았고, 생존율이 실제보다 낮게 나오는 방향의 편향이다.**

## 4. 공간해상도 — 어디까지 좁힐 수 있나 **[실측]**

### 먼저: 좌표계는 문서를 믿으면 안 된다

두 소스의 좌표계를 **역지오코딩으로 확정**했다. 각 레코드의 좌표를 변환해 카카오 역지오코딩에 넣고, 그 레코드 자신의 주소에 적힌 자치구와 대조하는 방식이다.

| 소스 | 정답 | 오답 후보 |
|---|---|---|
| 인허가(LOCALDATA) | **EPSG:5174 — 120/120 (100.0%)** | 2097 = 90.8% · 5181 = 89.2% |
| 서울 상권 중심점 | **EPSG:5181 — 80/80 (100.0%)** | 2097 = 93.8% · 5174 = 90.0% |

**왜 이걸 따로 검증해야 하는가.** 후보 좌표계들은 원점이 같고 datum shift만 달라서, 틀린 것을 골라도 점이 여전히 서울 안에 그럴듯하게 떨어진다. 내부 검증(건수 일치·NULL 규칙·단조성 등 14종)이 **전부 통과하는데도** 모든 점포가 100~200m 밀려 있을 수 있다. **격자가 100m이므로 이는 1~2칸 오차**이고, 격자 단위 추천에서는 치명적이다.

실제로 이 프로젝트에서 처음엔 인허가를 EPSG:2097로 가정했고 내부 검증 14/14가 통과했다. 역지오코딩 대조에서 91%만 일치하며 **불일치가 전부 인접 자치구로 밀린 패턴**(강남구 도곡동→서초구, 서초구 방배동→동작구)이라 잡혔다. 검증 코드는 `probe/p8_crs.py`이며, 좌표계를 바꾸기 전에 반드시 다시 돌릴 것.

| 소스 | 실제 최소 단위 | 서울 커버리지 |
|---|---|---|
| 소상공인 상가정보 | **필지(PNU) + 건물 + 층/호** | 전역 |
| 인허가 이력 | **점포 좌표**(89.6%) + 시설면적 | 전역 |
| 카카오/구글 | 점포 좌표 | 전역 |
| 생활인구 | 행정동 (서울 424개) | 전역 |
| **상권 매출·유동인구** | **상권 1,650개** | **면적 27.2%** |

### 판정
**추천 단위는 100m 격자로 하고, 상권 내/외를 다른 스펙으로 다룬다.**

- 50m는 셀의 41%에 점포가 1개뿐이라 통계가 성립하지 않는다
- 200m는 골목 하나를 넘어서서 "이 자리"라는 감각을 잃는다
- 100m는 셀당 누적 3개(전체 환산 약 16개), 도보 1분 반경 — 자영업자가 체감하는 "이 골목"과 일치한다

## 5. 남은 리스크

1. **배달 수요 사각지대 (요식업 고유·미해결).** 배달 플랫폼은 공개 API가 없고 크롤링은 약관 위반이다. 우리 데이터는 홀 수요만 본다. 대응은 (a) 야간 체류인구·거주인구를 배달 잠재수요 프록시로 **명시적으로 이름 붙여** 넣거나 (b) "홀 중심 업태"로 범위를 선언하거나 둘 중 하나다. 심사에서 반드시 나온다
2. **양도양수 오분류** (§3) — 생존율을 낮은 쪽으로 왜곡
3. **상권 폴리곤 미확보** — 원 근사로 계산한 57.6%는 재계산 대상
4. **수도권 확장 시 지표 단절.** 서울 "추정매출/상권"과 경기 "카드소비/행정동"은 같은 지표가 아니다. 전 지역 공통분모는 소상공인 상가정보 + 인허가 이력뿐. **서울=풀스펙 / 수도권=축소스펙**의 2단 설계를 권한다. 경기데이터드림은 통신(KT)+카드(**KB국민** 포함) 결합 데이터를 일 단위로 제공하므로 확장 1순위
5. **최근 코호트의 우편절단** (§3) — 그래프로 그릴 때 마지막 2개 연도는 점선 처리할 것

## 블로그 코퍼스(`absa_post`)의 두 가지 성질 — 2026-07-28 실측

인용하기 전에 이 둘을 함께 말해야 한다.

### 1. 본문이 아니라 검색 스니펫이다

`absa_run.py:130-136` 이 네이버 검색 API 의 `title + description` 을 태그 제거해
저장한다. 원문 페이지를 읽지 않는다.

```
n=40,665   중앙값 147자   평균 146자   최대 281자   700자 초과 0.00%
```

판정 코드의 `txt[:700]` 절단은 한 번도 작동한 적이 없다. **지금까지 비정형 판정
전부가 147자 스니펫 위에서 이뤄졌다.** 원문 URL 은 저장돼 있지 않다.

### 2. 36.4% 는 그 가게 글이라는 근거가 본문에 없다

수집 쿼리는 `{동} {상호명}` 인데 **네이버 블로그 검색은 AND 가 아니다.**

```
상호명이 본문에 그대로 등장      21,522 (52.9%)
공백·기호를 무시하면 추가로       4,344 (10.7%)
둘 다 아님                     14,799 (36.4%)
```

`(place, mgtno)` 로 붙인 점포 귀속의 3분의 1 이상이 본문 근거가 없다는 뜻이다.
§I-20 에서 두 독립 판정자가 "대상 점포가 아님"이라고 한 비율(36.4%)과 같은 값이다.

**점포 단위 집계를 만들 때는 상호명 포함 여부로 먼저 걸러야 한다.** 다만 그렇게
걸러도 §I-20 의 정밀도는 13.4% → 14.8% 로 거의 움직이지 않았다(CI 겹침) —
귀속은 별개의 결함이지 정밀도 실패의 주원인이 아니다.
