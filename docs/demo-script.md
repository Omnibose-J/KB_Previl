# 데모 영상 촬영 대본 (무음 · 화면만 · 약 2분 20초)

무대: **한식 · 종로3가역 상권** (1·2등급 밀집, 매출 데이터 보유 — 전 기능 작동 확인됨).
촬영 전: `python run.py` → 브라우저 전체화면 · 줌 100% → 아래 격자 3개 미리 한 번씩 클릭(워밍).

무음이므로 **핵심 숫자 위에 마우스를 1~2초 머물러** 시선을 유도한다.

## 장면 순서

### 1. 랜딩 — 0:00~0:10
스크롤 한 번 천천히 내렸다 올린다. (53.5만 건 · 100m 격자 문구가 지나가게)

### 2. 입지판별 — 0:10~0:45
| 입력 | 값 |
|---|---|
| 업종 | 한식 |
| 지역 | 종로구 |
| 예산 | 보증금 10,000만 · 월세 300만 (기본값 있으면 그대로) |

결과 지도 → 종로3가 일대로 줌인 → **돈의동 39 일대** 격자(`9549_19526`, 1등급) 클릭.
머무를 곳: **등급 뱃지 → 실측 생존율(1등급 80.1%) → 1·2·3년 생존곡선**.

### 3. 권리금 리포트 — 0:45~1:25
같은 상세 화면의 권리금 카드에서:

| 입력 | 값 |
|---|---|
| 권리금 호가 | 5,000만 |
| 잔여 계약 | 3년 |
| 시설 자산(선택) | 취득 1,000만 · 경과 2년 · 내용연수 5년 |

분해 결과(시설/영업/바닥)가 뜨면 **3초 정지**. 머무를 곳: 분해 막대 → 추정 참고가 → 호가와의 차액.

### 4. 매물 비교 — 1:25~2:10
비교 화면에서 매물 3곳 입력 (전부 같은 상권 · 면적 45㎡ · 1층).
자리는 **지도 클릭**으로 고른다 — 행정동 점프에서 «종로1·2·3·4가동» 선택 후
종로3가역 북측(돈의동 먹자골목)으로 줌인하면 세 칸이 서로 붙어 있다. 클릭하면
슬롯에 주소 라벨이 뜨므로 아래 «주소 라벨»과 일치하는지 확인.

| 매물 | 클릭할 자리 (주소 라벨) | 격자 | 등급 | 보증금 | 월세 | 권리금 |
|---|---|---|---|---|---|---|
| A | **돈의동 39 일대** (#2와 같은 칸) | `9549_19526` | 1 | 10,000만 | 250만 | 6,000만 |
| B | **돈의동 125 일대** (A의 남동쪽 대각 옆칸) | `9550_19525` | 2 | 3,000만 | 380만 | 0 |
| C | **관수동 4 일대** (A에서 남쪽 두어 칸, 청계천 방향) | `9548_19523` | 1 | 5,000만 | 300만 | 3,000만 |

결과: 월세 순위 **A→C→B**가 실질 비용에서 **B(390만)→C(400만)→A(450만)**으로 역전.
머무를 곳: **교차하는 선 → 실질 월 점유비용 열**. 3초 정지.

### 5. 마무리 — 2:10~2:20
상세의 한계 문구("1등급도 약 20%는 폐업")를 1~2초 비추고 랜딩으로 돌아가며 끝.

## 주의
- `/api/report`(LLM 요약) 버튼은 누르지 않는다 — 네트워크 의존.
- 비교 값은 위 표 그대로 — 실질 비용 450/390/400 확인은 리허설 때 1회.
