# 기획안

### 0. 서비스 개요

- **가칭: KB 터(TEO)** — "AI 기반 상권·입지 추천 서비스"
- **한 줄 정의**: 예산·업종만 입력하면, 서울 내에서 **어느 동 → 어느 블록/건물 → 어느 매물**에 들어가야 하는지를, 정형·비정형 데이터를 융합해 **예상 매출·손익분기·생존확률**과 그 근거까지 제시하는 예비 창업자용 입지 결정 서비스
- **핵심 산출물**: 후보 매물 랭킹 + 매물별 "예상 월매출 / 손익분기 도달 개월 / 3년 생존확률 / 위험요인" + 자연어 근거 리포트

---

### 1. 문제 정의 및 필요성 (15점)

- **문제**: 자영업 창업의 성패는 입지가 절반 이상인데, 예비 창업자는 입지 판단을 **부동산 중개인의 감(勘)·주변 소문·직접 발품**에 의존함. 유동인구·매출·임대료·상권 반응이 흩어져 있어 **정보 비대칭**이 심함.
- **필요성 (수치로 뒷받침)**: 한국 자영업의 5년 생존율은 전 업종 최저 수준이며, 폐업의 상당수가 "잘못된 입지 선택"에서 발생. → 개인에겐 생계 리스크, **금융사(KB)에겐 소상공인 대출 부실 리스크**로 직결됨.
- **왜 지금·왜 KB인가**: 공공 상권데이터(서울시·소진공)가 개방되었고 LLM으로 비정형 반응 분석이 가능해진 지금이 타이밍. 그리고 이 문제는 **KB의 이해관계와 정확히 일치**함 → 대출 나가기 전에 입지 리스크를 낮추면 부실이 줄고, 예비 창업자를 대출·소호 플랫폼 고객으로 전환할 수 있음. "착한 서비스"가 아니라 KB에게 돈이 되는 서비스라는 점이 필요성의 핵심.

---

### 2. 타깃 & 사용 시나리오

- **타깃**: 창업 예산이 정해져 있고 업종은 잡혀 있으나 입지를 못 정한 예비 소상공인 (1차: 카페·음식점 등 오프라인 F&B)
- **시나리오**:
    1. 입력 → "보증금+월세 예산 5,000만/월 250만, 업종 = 브런치 카페, 희망 반경 = 서울 전역"
    2. 1차 필터 → 예산·업종 부적합 매물 제외
    3. AI 스코어링 → 동/블록별 적합도 산출, 상위 후보 랭킹
    4. 결과 → "성수2가 A블록 매물 3건 / 예상 월매출 1,900만 / 손익분기 8개월 / 3년 생존확률 62% / 위험요인: 임대료 상승·경쟁 카페 밀도 상위 10%"
    5. 근거 리포트 → "이 지역은 최근 6개월 SNS 언급 +38%, 2030 여성 유입 우세, 주말 유동 집중형…" + KB 창업자금 대출 한도 시뮬레이션 연결

### 3. 핵심 기능 & 산출물 (창의성·효과 20점)

경쟁작과 갈리는 지점을 4개로 명시합니다.

- **(창의성 ①) SNS 반응 = 매출 선행지표화**: 카드매출·유동인구는 "이미 뜬 상권"을 알려주는 후행지표. 반면 인스타 지오태그·블로그·리뷰 증가율은 **뜨기 직전 상권**을 잡아냄. 정형(현재 실적) + 비정형(미래 모멘텀)을 한 점수로 합치는 게 차별점.
- **(창의성 ②) 업종별 동적 가중치**: 같은 매물이라도 업종마다 좋은 입지가 다름(카페=주말·2030 유동, 저녁 술집=직장인구·야간 유동). 업종을 넣으면 가중치가 바뀌어 **"이 자리는 카페엔 A등급, 고깃집엔 C등급"**처럼 나옴.
- **(창의성 ③) 감(勘)이 아닌 숫자**: 추천에서 끝나지 않고 **예상 매출·손익분기·생존확률**이라는 정량 지표로 의사결정을 지원.
- **(효과) 설명가능성**: 왜 이 매물인지 근거 데이터를 인용한 자연어 리포트를 함께 제공 → 신뢰·설득력 확보 (블랙박스 추천의 약점 해소).

### 4. 데이터 설계

**정형 (모두 API/공공데이터로 확보 가능)**

- 유동인구: 서울시 생활인구(통신 기반), KT/SKT 유동인구, 지하철·버스 승하차(T-money)
- 매출(추정): **서울시 우리마을가게 상권분석서비스**의 업종별 추정매출 → MVP의 정답(label)로 사용. *스케일업 시 KB국민카드 가맹점 실매출로 교체 → 정확도 급상승*
- 임대료/시세: 한국부동산원 상업용 임대동향, 국토부 상업용 실거래가, **KB부동산 시세**
- 상권 구조: 소상공인시장진흥공단 상권정보 API(업종별 점포 수·밀도·개폐업)
- 생활 인프라·경쟁강도: 카카오/네이버 지도 POI(동종업종 밀도, 배후 인구)
- 팝업스토어: 팝업 정보 사이트·인스타 크롤링(상권 화제성 프록시)

**비정형**

- SNS: 인스타 해시태그/지오태그, 네이버 블로그·카페, X, 유튜브, **지도 리뷰(카카오/네이버)**
- 뉴스: "○○동 뜬다/젠트리피케이션" 류 기사

**추가로 붙이면 좋은 데이터 (가점 요인)**

- 배달 데이터(배달 수요 밀도) — F&B 매출 설명력 큼
- 날씨·요일·시간대별 유동 패턴, 공실률(빈 점포율), 프랜차이즈 신규출점 위치(대기업이 검증한 입지 = 프록시)

### 5. 기술 아키텍처 & AI 모델 (기술 적정성 20점)

**4-Layer 구조**

1. **수집 계층**: 공공 API 정기 수집 + SNS/지도 리뷰 크롤러 → 원천 저장(PostgreSQL/Object Storage)
2. **처리 계층**
    - 정형: 결측·이상치 처리, 상권/블록(약 100~300m 격자) 단위로 시계열 집계·정규화
    - 비정형(핵심):
        - **지리 매핑** — SNS 텍스트를 "어느 상권"에 귀속. 지오태그 우선, 없으면 장소명 개체명인식(NER)으로 상권 매핑
        - **감성·토픽 분석** — 한국어 특화 모델(KLUE-RoBERTa/KcELECTRA) 파인튜닝 또는 LLM few-shot으로 긍/부정·기대감·업종키워드 분류 → **상권별 반응지수·모멘텀(증가율)** 산출
3. **분석·추천 계층 (2-트랙 결합)**
    - **정량 코어 = 매출/생존 예측 모델**: 입력(정형+비정형 통합 feature vector + 업종) → 출력(예상 월매출·손익분기·3년 생존확률). 모델은 **Gradient Boosting(XGBoost/LightGBM)** 회귀·분류 — 표 형태 데이터에서 성능·해석력이 좋고 SHAP로 기여 변수 추출 가능
    - **해석·생성 layer = LLM**: 예측 결과 + 상위 기여 변수를 **RAG로 근거 데이터를 인용**해 자연어 리포트 생성. LLM은 "왜"를 설명하는 역할이지 숫자를 만드는 역할이 아님 → 환각·신뢰 문제 차단
4. **서비스 계층**: 입력 폼 → 지도 기반 결과(랭킹·히트맵) 대시보드. 프로토타입은 **Streamlit/React + 지도 SDK**

**기술 적정성의 논리(심사 포인트)**: "LLM에 다 물어보면 되지 않나?"에 대한 답 = **정량 예측은 통계·ML 모델이, 설명·비정형 처리는 LLM이** 맡는 역할 분리. 각 기술을 그게 잘하는 데에만 쓴다는 점을 명시하면 "기술을 왜 이렇게 골랐는가"에서 점수가 나옵니다.

### 6. 추천 로직 상세

- **Step 1 필터링**: 예산(보증금·월세) + 업종 적합성으로 후보 매물/블록 축소
- **Step 2 스코어링**: 업종 가중치 × [유동적합·배후인구·경쟁밀도(역)·임대료부담(역)·SNS반응·모멘텀] → 입지 적합도 점수
- **Step 3 정량 예측**: 후보별 예상 매출·손익분기·생존확률 산출(§5 정량 코어)
- **Step 4 랭킹 + 리포트**: 상위 N개 매물 정렬, SHAP 상위 변수로 근거 리포트 자동 생성
- **가중치 학습 방식**: 초기엔 도메인 규칙 기반 → 이후 실제 추정매출을 label로 지도학습해 업종별 최적 가중치 도출

### 7. 개발 계획 / 로드맵 (개발 구체성 15점)

공모전 기간 내 **실제로 만들 수 있는 범위**로 스코프를 좁힌 게 핵심입니다.

- **Phase 0 (1주)**: 파일럿 범위 확정 — **성수·연남·홍대 등 2~3개 상권 × 카페·음식점 2개 업종**. 전 서울·전 업종은 스케일업 목표로 명시
- **Phase 1 (2주)**: 정형 데이터 파이프라인 구축(상권분석·유동인구·임대료 API 연동), 블록 단위 집계
- **Phase 2 (2주)**: 비정형 파이프라인 — 지도 리뷰·인스타 수집 → 지리 매핑 → 감성·토픽 분석 → 반응지수화
- **Phase 3 (2주)**: 매출·생존 예측 모델 학습(추정매출 label), SHAP 기여도, 업종 가중치 튜닝
- **Phase 4 (1~2주)**: LLM 근거 리포트(RAG) + 지도 대시보드 MVP
- **Phase 5 (1주)**: 파일럿 상권 사후검증(실제 화제 상권과 모델 랭킹 일치도 확인), 데모·발표자료

산출물 명시: 데이터 파이프라인 코드 / 예측 모델 / 감성분석 모듈 / 지도 대시보드 데모 / 성능표(예측 오차·랭킹 일치도).

### 8. KB 연계 & 활용 가능성 (15점)

- **데이터 시너지**: KB국민카드 가맹점 실매출 → 매출 예측의 정답 데이터(공공 추정매출보다 정확). KB부동산 시세·매물 → **매물 단위 추천을 실제로 실현**. 이 두 자산이 붙는 순간 정확도·해상도가 공공데이터 대비 크게 상승
- **수익·전환 모델**: 입지 추천 → **KB 소상공인 창업자금 대출 연계**(예상 매출 기반 한도 시뮬레이션). 예비 창업자 → KB 대출·**KB 사장님플러스(소호 플랫폼)** 고객으로 전환하는 퍼널
- **리스크 관리 가치**: 입지 리스크가 낮은 창업자에게 대출이 나가면 **소상공인 대출 부실률↓**. 즉 마케팅 도구인 동시에 **여신 심사 보조 지표**로도 활용 가능
- **확장성**: 서울 → 전국, F&B → 편의점·미용·학원 등 업종 확장, B2B(프랜차이즈 본사 출점 컨설팅)로 판매 가능

### 9. 현실성 및 한계

**진짜 어려운 3가지**

1. **매물 단위 데이터**: "어느 매물"까지 가려면 실시간 상가 매물 DB(네이버부동산·점포라인 등)가 필요한데 크롤링 제약·최신성 문제가 큼. → **현실 대응**: MVP는 "동·블록·건물 단위 추천 + 예시 매물"까지. 매물 단위는 KB부동산/제휴 매물 연동을 전제로 한 스케일업 과제로 명확히 구분
2. **SNS → 상권 지리 매핑**: 지오태그 없는 게시물이 많고 "성수"처럼 범위가 모호. → 지오태그·장소태그 있는 데이터 우선 사용, 나머지는 보조지표로만 반영해 노이즈 통제
3. **매출 데이터의 벽**: 공공 추정매출은 업종·구간이 뭉뚱그려짐(실측 아님). KB카드 실매출 없이는 예측 정확도에 상한이 있음. → 그래서 KB 연계가 스케일업의 필수 조건이라는 점을 오히려 강점으로 프레이밍

**그 외 한계**

- 인과 아님: 유동인구·SNS가 매출과 상관은 있어도 인과 보장 안 됨 → "참고 점수"로 포지셔닝, 최종 판단은 사용자
- 콜드스타트: SNS 데이터 적은 신흥·주거지 상권은 예측 신뢰도↓ → 신뢰구간·데이터 충분성 표기
- 크롤링 약관·개인정보: 공개 데이터·API 우선, 리뷰는 집계 통계로만 사용

## KB가 이 서비스로 얻는 이득

### 1. 신규 수익 — 여신 잔액이 직접 늘어난다

**① 창업자금 대출의 신규 유입 채널**

지금 KB의 창업자금 대출은 "창업을 결심하고 은행에 찾아온 사람"만 받습니다. 이 서비스는 **결심하기 전 단계, 즉 '어디에 낼까' 고민하는 시점**에 고객을 붙잡습니다. 창업 의사결정 퍼널의 최상단을 선점하는 것이고, 여기서 잡은 고객은 자연히 KB에서 대출을 받게 됩니다.

**② 대출 전환율이 구조적으로 높다**

"예상 월매출 1,900만 / 손익분기 8개월"이라는 숫자를 본 직후에 "이 매출이면 KB에서 최대 ○○만원, 금리 ○%" 시뮬레이션이 뜹니다. **구매 의사가 가장 높은 순간에 상품이 제시**되므로, 배너 광고식 유입과는 전환율이 다릅니다.

**③ 한 명당 상품이 줄줄이 딸려온다 (LTV)**

자영업 창업자 1명 = 창업자금 대출 + 사업자 계좌 + 카드 가맹점(KB국민카드) + 매출대금 정산 + 임대차 보증금 대출 + 화재보험(KB손보) + 나중엔 운전자금·개인 주담대까지. **KB금융 계열 전체가 먹는 구조**입니다. 개인 고객 1명보다 소상공인 1명의 생애가치가 훨씬 큽니다.

**④ B2B 판매 가능**

프랜차이즈 본사 출점 전략, 부동산 임대인·리츠·시행사 대상으로 이 분석 엔진 자체를 유료 제공 가능. KB가 이미 부동산 데이터(KB부동산 시세)를 파는 회사라는 점에서 자연스러운 확장입니다.

### 2. 비용·리스크 — 사실 여기가 은행에 더 큰 돈

**⑤ 소상공인 대출 부실률 하락 (가장 임팩트 큰 항목)**

소상공인 대출 부실의 근본 원인 중 상당수가 **폐업**이고, 폐업 원인의 큰 축이 **입지 실패**입니다. 대출 나가기 전에 입지 리스크를 걸러내면 연체·부실이 줄어듭니다. 매출 증대보다 **대손비용 감축이 은행 손익에 더 직접적**이고, 여기에 이 서비스의 본질적 가치가 있습니다.

**⑥ 여신 심사 보조 지표로 재활용**

같은 엔진을 뒤집으면 심사 도구가 됩니다. 신청자가 계약하려는 그 자리에 대해 **"이 입지×업종 조합의 예상 매출과 3년 생존확률"**을 산출해 심사에 참고 지표로 넣을 수 있습니다. 지금 소상공인 심사는 신용점수·담보 위주라 **'사업 자체가 될 자리인가'를 보는 축이 사실상 없습니다.** 그 빈칸을 메우는 새로운 심사 변수입니다. → 고객용 서비스 하나 만들어서 **심사 모델까지 개선**되는 1석 2조.

**⑦ 컨설팅 인력 병목 해소**

KB 소상공인 컨설팅은 전문가 1:1이라 **상담사 수만큼만 처리 가능**합니다. AI가 1차 스크리닝(후보 지역 압축·정량 근거 생성)을 맡으면 상담사는 최종 코칭에만 집중 → **같은 인력으로 처리량이 늘고, 상담사별 품질 편차도 줄어듭니다.** 인건비를 늘리지 않고 서비스 커버리지를 확대하는 방법입니다.

### 3. 데이터 — KB만 가능한 해자가 만들어진다

**⑧ KB 데이터 자산이 '수익 나는 형태'로 바뀐다**

KB국민카드 가맹점 실매출, KB부동산 시세, 소상공인 대출 상환·연체·폐업 이력 — 이건 이미 KB 안에 있지만 **각각 다른 목적으로 쌓여 있고 잠들어 있는** 데이터입니다. 이 서비스는 그 세 개를 하나의 예측 모델로 엮는 **활용처**입니다. 특히 대출 이력은 "이 입지에서 창업한 사람이 실제로 살아남았는가"라는 **정답 데이터**인데, 이걸 가진 곳은 사실상 은행뿐입니다.

**⑨ 복제 불가능한 진입장벽**

공공데이터로 만든 상권분석 서비스는 누구나 만듭니다. 하지만 **실매출 + 실제 폐업/상환 결과**로 학습한 생존 예측 모델은 **KB 아니면 못 만듭니다.** 핀테크·부동산 스타트업이 따라올 수 없는 지점이고, 발표에서 "이 서비스는 KB에서만 완성된다"고 못박을 근거입니다.

**⑩ 데이터 선순환**

사용자가 조건을 입력하고 후보를 비교하는 행동 자체가 데이터입니다. "요즘 예비 창업자들이 어떤 업종을, 어떤 예산대로, 어느 지역을 노리는가" — 이건 **어떤 통계로도 안 잡히는 창업 수요 선행지표**로, KB의 소상공인 상품 기획·금리 정책에 직접 쓰입니다. 쓸수록 모델이 정확해지는 구조라 시간이 갈수록 격차가 벌어집니다.

### 4. 고객·전략

**⑪ 비고객 확보 채널**

KB bridge가 이미 **비고객에게도 무료 개방**돼 있다는 건, KB가 이 영역을 **고객 획득 채널로 본다**는 뜻입니다. 이 서비스는 그 전략의 훨씬 강력한 버전입니다. 창업 준비생은 아직 주거래 은행이 정해지지 않은 **미개척 고객군**이고, 첫 사업자 계좌를 튼 은행이 그 사업의 평생 주거래가 됩니다. **락인 효과가 매우 강한 시장**입니다.

**⑫ 소호 생태계 완성**

KB엔 이미 조회(bridge 상권분석) · 상담(소상공인 컨설팅) · 자금(창업자금 대출) · 운영(KB사장님플러스)이 다 있습니다. 없는 건 **"그래서 어디로 가야 하는가"에 답하는 결정 엔진** 하나입니다. 이걸 끼우면 **입지 결정 → 자금 조달 → 개업 → 운영 관리**가 하나의 흐름으로 이어져, 흩어진 서비스들이 **하나의 퍼널**이 됩니다. 신규 서비스 하나가 기존 서비스 전부의 가치를 끌어올리는 구조입니다.

**⑬ 컨설팅 5개 영역 전체를 데이터로 무장**

상권분석은 직접 대체·증강, 창업 일반은 타당성 검토 근거 제공, 금융 상담은 대출 한도 산정, 경영 상담은 SNS 반응 기반 마케팅 인사이트 — **5개 중 4개 영역**에 붙습니다. (세무·법률은 연결이 약하니 발표에서 억지로 끼우지 마세요.)

**⑭ ESG·브랜드**

자영업자 폐업 방지는 **금융의 사회적 책임 성과**로 그대로 보고 가능한 주제입니다. "대출 많이 팔았습니다"보다 "**입지 실패로 인한 폐업을 줄였습니다**"가 훨씬 좋은 스토리이고, 규제당국·언론 대응 측면에서도 유리합니다.
