# 실험 설계 — 라운드 2 (제출 전 마지막 실험 창)

작성 2026-07-27 (v2 — 절제 프로그램 중심으로 재설계) · 마감 2026-08-03 · 소유: 레인 A · **실행 결과는 `docs/model-findings.md`에 기록한다.**

**이 라운드의 목표는 둘이다 — 그 외 전부는 이 둘을 위한 보조다.**

1. **최고의 모델 찾기** (E-M): 후보 모델 토너먼트로 승자를 확정한다.
2. **각 피처의 가중치 확정** (E-A): 승자 모델 위에서 피처(군) 기여도를 절제·중요도·계수 3중으로 측정한다.

실행은 3단계 파이프라인이다. 순서가 논리다 — 데이터가 바뀌면 모델 선발이 무효가 되고, 모델이 바뀌면 가중치가 무효가 되므로 역순 실행 금지:

```
Stage 1. 데이터 확정   E0(배포 정합) · E1(학습 기간) · E2(라벨) → train/label 고정
Stage 2. 모델 선발     E-M 토너먼트 → 승자 확정
Stage 3. 가중치 측정   E-A 절제 프로그램 (+ 확장 피처 편입) → 기여도 표
보조                  E3(horizon) · A1·A2(UI 산출물) · E4·E5(피처 후보 검증)
```

**최종 산출물 2장**:
- **모델 선정 표**: 후보 × {내부 검증 AUC·Brier} + 승자의 홀드아웃 성적 — "여러 모델을 검증하고 골랐다"의 증거.
- **피처 가중치 표**: 피처(군) × {절제 ΔAUC±CI, 단독 AUC, 순열 중요도, 로짓 계수 방향} — 발표(기술 적정성)와 UI "왜 이 자리인가"의 단일 근거. 개별 피처 수준의 "가중치"는 승자 모델의 순열 중요도 + 로짓 계수(방향)로, 군 수준은 절제 ΔAUC로 읽는다(겹침 때문에 층위가 다르다 — E-A 참조).

## 0. 공통 규약 — 모든 실험에 적용, 예외 없음

1. **사전 등록.** 성공/기각/해석 기준은 이 문서가 전부다. 실행 후 임계·split·지표 변경 금지. 미달이면 negative로 기록한다.
2. **시간 분리 고정.** train 2013–2018 / test 2019–2022. 예외는 명시된 것만: E1·E3(기간 자체가 실험 대상), E-M·확장 피처 선별의 내부 검증 분할(train 내부에서만 가른다). 무작위 분할 금지.
3. **as-of 가드.** 피처 추가·변경 시 `model/asof.py`의 `FEATURES`에 관측 시점 근거 등재 + `python -m model.test_leakage` RED→GREEN.
4. **헤드라인은 순수 입지(LOC3) 기준** — 수치 계보는 `model-findings.md` §4-C. 비교 앵커: AUC 0.5909 · 상위10% 74.3% · 하위10% 44.8%.
5. **베이스라인 동반 재계산.** 라벨·기간이 바뀌면(E1·E2·E3) `prior_surv` 등 베이스라인 3종을 같은 조건에서 재산출해 비교한다.
6. **채택 시 절차.** `service/precompute` 재실행 → `grid_score` 스키마 불변 확인 → 레인 B 통보 → §4-C·README·CLAUDE.md 수치 갱신.

## E-A. 피처군 절제 프로그램 — 이번 라운드의 중심 (P0)

### 왜 군 단위인가

인허가 파생 7개를 **블록 추가**해도 ΔAUC 0.0000이었다 — 이 데이터는 정보 중복이 커서, 단일 피처를 하나 빼도 이웃 피처가 자리를 메울 가능성이 높다(단일 leave-one-out 실험 자체는 아직 없다 — 그래서 "전부 0"으로 나올 위험을 설계로 막는다). **절제 단위는 서로 다른 정보 원천을 대표하는 피처군**이고, 단일 피처 수준은 순열 중요도·로짓 계수로 보조 측정한다.

**사전 등록 폴백**: G1·G2·G3은 전부 인허가 원천이라 군끼리도 겹칠 수 있다. 셋 다 CI∋0이면 인허가군을 통째로 묶은 2차 절제(G1+G2+G3 전체 제거 vs full)를 추가 실행해 **원천 수준 기여**를 보고한다 — "군별 판별 불가"로 표가 비는 것을 막는 안전망.

### 유니버스 확장 후보 — 정형 (수집 난이도 순)

**Tier 1 — 인허가 재파생 (수집 0, 반나절).** 전례 주의: 파생 7개 추가 ΔAUC 0.0000의 포화 판정이 있다. 단 아래는 기존 파생과 다른 메커니즘(공실 동학·체인 신호)이라 측정 가치는 있고, 기대는 낮게 사전 등록한다.

| 후보 | 정의 | 가설 |
|---|---|---|
| 공실 회전 속도 | 같은 주소 폐업→다음 개업까지 중앙값 개월 | 빨리 다시 차는 자리 = 수요가 검증된 자리 |
| 재점유율 | 폐업 후 12개월 내 재개업 비율 | 〃 |
| 폐업 나이 | 격자 내 폐업 점포의 영업 기간 중앙값 | 일찍 죽는 자리 vs 오래 살다 바뀌는 자리 |
| 격자 나이 | 첫 인허가 이후 경과 연수 | 상권 성숙도 |
| 체인 비중 | 서울에 동일 상호 N개 이상인 점포의 비중 | 체인은 입지를 전문적으로 고른다 — 그 존재가 검증 신호 |
| 밀도 기울기 | 5×5(r2) 대비 3×3(r1) 밀도 비 | 상권 핵심부인가 가장자리인가 |
| 단기 성장 | openings_12m (36m의 단기판) | 과열 신호의 시간 해상도 |
| 업태 전환율 | 같은 주소에서 업태가 바뀐 재개업 비율 | 자리 정체성 불안정 |
| 직권말소 비율 | 폐업 중 직권말소 비중 (필드 존재 시) | 행정 정리 vs 실제 폐업 — 라벨 품질 신호 |

**Tier 1 공통 as-of 절대 조항 — 위 정의들은 그대로 구현하면 미래창 누수다.** 전부 T(대상 점포 개업 시점) 이전 관측만으로 재정의한다: 재점유율은 `폐업 ≤ T−12`인 폐업만 분모(그래야 12개월 창이 T 이전에 닫힌다) · 공실 회전은 T에 아직 안 찬 공실을 우측중도절단으로 처리 · 체인 비중은 `개업 ≤ T` 점포만 집계(**N=3**) · 업태 전환·폐업 나이도 `≤ T` 사건만. 각 피처는 `asof.py FEATURES`에 ≤T 절단 조항을 명기하고, **"T 이후 행을 전부 지워도 값이 불변"인 셀프테스트**를 피처별로 통과해야 한다. 이유: 기존 leakage 가드는 기본 NUM 세트만 검사하고 임계도 AUC 0.90이라 **신규 피처의 +0.02급 누수를 못 잡는다** — 가드가 침묵한다고 안전한 게 아니다.

**Tier 2 — 타 인허가 업종 (LOCALDATA 동일 포맷·동일 as-of 재구성, 수집 ~1일). 가장 유망.** 현재 데이터는 일반음식점뿐이라 **휴게음식점 카페(스타벅스 등 대부분의 카페)가 경쟁·집적 신호에서 통째로 빠져 있다.** 전 이력(개·폐업일)이 있어 as-of 완전:

| 후보 | 신호 |
|---|---|
| 휴게음식점 밀도·동학 | 카페·패스트푸드 경쟁 및 집적 — 현재 실명 사각지대 |
| 유흥·단란주점 밀도 | 야간 상권 성격 |
| 병원·약국 밀도 | 주간 유동 앵커 |
| 학원 밀도 | 학생·학부모 유동 |
| 숙박업 밀도 | 관광 수요 |

**Tier 3 — 외부 공공 시계열 (as-of 재구성 가능한 드문 외부 소스, 수집 1~2일).**

| 후보 | as-of 근거 |
|---|---|
| 지하철 역별 승하차 (월별, 2008~) | 개업 직전 12개월 평균·증감 — `grid_access` 최근접 역에 조인. 역 단위 값임을 표기 |
| 버스 정류장별 승하차 (2013~) | 〃, 정류장 단위라 지하철보다 공간 해상도 높음 |
| 개별공시지가 (연도별 공표) | 개업 연도의 지가 수준·직전 3년 상승률 — 임대료 프록시. 필지 단위 = 점 단위 |
| 아파트 준공일·세대수 | 개업 시점 기준 반경 내 준공 완료 세대수 — 배후 수요의 as-of 복원 |
| 건축물대장 표제부 | 사용승인일 기준 반경 내 용도별 연면적(오피스=직장인구 프록시) |

**Tier 4 — 정적 지리 (시간 불변이라 as-of 논란 자체가 약함, 각 반나절).** 경사도·표고(DEM) · 대로 접면·코너 여부(OSM 도로망) · 하천·공원·대학·전통시장 거리 · 정비구역 지정 여부(지정일 있음 — 멸실 위험 신호).

**마감 내 실행 컷**: Tier 1 전부 + Tier 2 휴게음식점 + Tier 3 지하철 승하차. 나머지는 후보로 기록만 하고 제출 후 과제로 넘긴다 — 수집이 하루를 넘기면 절제표 일정을 잡아먹는다.

**확장 피처의 편입 기준 (사전 등록)**: 절제표 **측정에는 전부** 들어간다. 그러나 **순위 모델(배포 세트) 편입은 별도 관문이고, 홀드아웃 다중 조회 금지가 여기에도 적용된다** — 후보가 ~20개인데 홀드아웃 AUC 표준오차가 ≈0.003이라, 후보마다 홀드아웃을 보면 +0.002 문턱은 순수 노이즈도 통과시킨다(E-M에서 금지한 것과 동일한 실수). 절차:
1. **선별은 내부 검증**(확정 train의 마지막 2년)에서 — 후보별 ΔAUC로 편입 후보군 결정.
2. **홀드아웃은 채택 번들 1회 확인만**: 편입 후보 전체를 묶어 1회 측정. 기준 = 짝지은 부트스트랩 ΔAUC **95% CI 하한 > 0** 그리고 점추정 ≥ +0.002(비정형 번들은 +0.005, 단측 — `experiment_mention --min-gain`과 동일) 그리고 상위10% 실측 **−0.5%p 이상 하락 없음** 그리고 robustness 자치구 25/25 유지.
3. robustness는 **후보 배포 세트로** 측정한다 — 현행 `robustness.py`는 NUM(면적 포함) 하드코딩이라 `--features` 인자 신설이 선행(레인 A, 7/28).

측정과 편입을 분리하는 이유: 가중치 표는 "무엇이 얼마나 아는가"의 지도이고, 배포 세트는 "그중 안정적으로 쓸 것"의 선별이다.

### 유니버스 확장 후보 — 비정형: "양"이 아니라 "내용"

두 번의 negative(§6·§6-B)가 기각한 것은 정확히는 **관심의 양(볼륨) 신호**다 — 남은 가설은 "언급량은 인기를 재는데 인기와 생존은 다른 축"이었다. 따라서 유의미할 가능성이 남은 비정형은 **같은 텍스트에서 다른 구성 개념을 재는 것**이다. 전부 날짜 있는 소스만 — as-of 불가 소스(현재 평점·리뷰·인스타)는 여전히 제외.

|---|---|---|---|---|---|
| U1 | **상호명 파싱** (인허가 데이터 내장 텍스트) | 12업태보다 가는 세부 업종 경쟁 구조("○○막창"·"△△파스타"), 네이밍 스타일(외래어 비중 = 상권 세대 교체 신호) | 완전 (개업일 내장) | 수집 0 | **P1 — 마감 내. 가장 싸고 가장 새로운 정보** |

U1·U2가 절제표에 들어가면 비정형 행이 "볼륨(기각 2회) vs 내용(신규 측정)"으로 나뉘어, 어느 쪽이 나와도 §6 서사가 강해진다: 기각이면 3번째 방식의 재확인, 기여하면 "볼륨이 아니라 내용이었다"는 정정.

### 방법 — 3중 측정 × 반복

전부 동일 하니스(`evaluate.load_split` + **E-M 승자 모델**), 홀드아웃 고정. 로짓 계수 보조는 승자와 무관하게 항상 logit으로 측정:

1. **전체 모델 두 벤치**: 순위 벤치 = **LOC3 그대로**(G0 포함 — G7은 기각돼 미포함) / 측정 벤치 = LOC3 + G6 + G7.
2. **Leave-one-group-out**: 군 하나 빼고 학습 → ΔAUC = full − without. "이 정보 원천이 사라지면 얼마나 잃는가."
3. **Only-one-group-in**: 군 하나만으로 학습 → 단독 AUC. "이 원천 혼자 얼마나 아는가." (겹침 때문에 2와 3은 다른 답을 준다 — 둘 다 싣는 것이 핵심.)
4. **반복**: 시드 5개 × 홀드아웃 부트스트랩 리샘플 200회로 ΔAUC 95% CI. **선행 코드 작업(레인 A, 7/28)**: `train.fit_predict`는 `random_state=0` 하드코딩이라 `seed=` 인자 추가가 필요하다. 결합 규칙: **ΔAUC는 시드 5개 예측을 평균한 벡터 위에서 1회 계산**하고, CI는 그 평균 벡터의 **짝지은(paired) 부트스트랩** 200회 — 같은 리샘플에서 full과 절제 모델의 AUC 차를 계산한다(따로 리샘플하면 CI가 부풀어 전부 "판별 불가"가 된다). 예측 벡터는 재사용하고 리샘플만 반복. **CI가 0을 포함하면 "기여 판별 불가(정보 중복)"로 보고** — 0이라고 쓰지 않는다.
5. 보조: 순열 중요도(피처 단위), 로짓 표준화 계수(방향).

### 사전 등록된 해석 규칙

- 이 프로그램은 채택/기각 실험이 아니라 **측정**이다. 결과가 어떻든 표 전체를 싣는다.
- 예상과 다른 부호·순서(예: G1이 음수 방향)가 나와도 임계를 바꾸지 않고 그대로 기록 + 해석 병기.
- G6(점포 속성)의 기여가 크게 나오는 것은 이미 아는 사실(면적 단독 AUC 0.6227)의 재확인 — **"순위에서 뺀 이유" 서사로 쓰고**, 순위 모델 복귀 근거로 쓰지 않는다.
- **G7은 별도 부표로만 측정한다**: 트렌드 데이터는 2016-01부터라 2013–2018 벤치에 넣으면 학습행 약 2/3가 결측 대치돼 **커버리지 이유로 구조적 0**이 나온다 — 그걸 "3번째 기각"으로 읽으면 안 된다. G7 행은 §6 하니스와 동일하게 train 2017–2018로 돌리고 "표본 제약: 2017–2018 학습" 라벨을 단다. 그 부표에서도 0 근처면 그때 §6·§6-B의 재확인으로 기록한다.

### 산출물

`docs/model-findings.md`에 §7 "피처군 기여도" 추가: 군별 {ΔAUC±CI, 단독 AUC, 상위10% 변화} 표 1장. 이 표가 (a) 발표 슬라이드 1장, (b) UI "왜 이 자리인가" 바의 가중치 원천, (c) "비정형은 측정했고 기여 없음"의 통합 증거가 된다.

**비용**: 학습 1회가 수 초~수십 초. 군 7(G1–G5·G6·G7) × 방향 2 × 벤치 고려 × 시드 5 ≈ **140회 학습** + 부트스트랩은 예측 재사용 — 충분히 하루 안. 스크립트는 `model/ablation.py` 신설(레인 A).

## E-M. 모델 토너먼트 — 여러 모델 중 최고 성능 선택 (P0)

지금은 logit·gbm 2종만 비교했다. 후보를 넓혀 제일 좋은 것을 고르되, **홀드아웃으로 고르면 그 자체가 선택 누수**(테스트를 여러 번 보면 테스트가 검증셋이 된다)이므로 선발과 확인을 분리한다.

**후보 (전부 LOC3, 동일 인코더) — 6종**: logit(현행) · LightGBM(현행) · RandomForest · ExtraTrees · HistGradientBoosting · MLP(소형 1–2층). XGBoost는 **미설치라 후보 제외**(설치하지 않는다 — 그 사실만 기록). **선행 코드 작업(레인 A, 7/28 오후)**: `train.fit_predict`는 현재 logit·gbm 2종만 구현이라 나머지 4종 래퍼 추가 + `service/precompute.py`에 `--model` 인자(gbm 하드코딩 해제)가 필요하다 — 이거 없이는 승자가 나와도 배포를 못 한다.

**선발 절차 (사전 등록)**:
1. **내부 검증으로 선발**: Stage 1에서 확정된 train의 **마지막 2년을 내부 검증**으로 뗀다(현행이면 2013–2016/2017–2018, E1 채택 시 2005–2016/2017–2018). 후보별 AUC·Brier 측정, 하이퍼파라미터 탐색도 이 안에서만.
2. 내부 검증 1위(동률 시 Brier → 단순한 모델 순)를 **승자로 확정한 뒤** 2013–2018 전체로 재학습.
3. **홀드아웃(2019–2022)은 승자 1회 + 현행 gbm 1회만 측정** — 후보 전체를 홀드아웃에 대보는 것 금지.

**채택 기준**: 승자 vs 현행 gbm의 짝지은 부트스트랩 ΔAUC **95% CI 하한 > 0 그리고 점추정 +0.003 이상** 그리고 십분위 단조 유지 그리고 `robustness` 연도·업태·자치구 통과(`--features` 후보 세트로). 미달이면 현행 유지 + "후보 6종 비교 결과 gbm 유지"로 기록 — 이것도 발표에서 "여러 모델을 검증하고 골랐다"는 근거가 된다.

**의도적 한계(사전 수용)**: 확장 피처 편입 후 승자 **재선발은 하지 않는다** — 승자는 Stage 1 확정 데이터·LOC3 기준이며, 피처가 늘면 모델 우열이 바뀔 수 있다는 한계를 결과 절(§7)에 명기한다. 마감 제약의 의도적 트레이드오프.

**연쇄 효과**: 승자가 바뀌면 E-A 절제표·backtest·precompute를 승자로 재산출한다. 따라서 **E-M을 E-A보다 먼저 돌린다** (7/28–29).

**전제 (Stage 1 선행)**: E1·E2가 train 기간·라벨을 바꾸면 토너먼트 데이터도 바뀌므로, E-M은 **E1·E2 판정이 끝난 확정 데이터** 위에서 돈다. E1·E2 자체의 채택 판정은 현행 gbm을 프로브로 쓴다(모델·데이터를 동시에 움직이면 원인 귀속이 안 된다).

## E1. 학습 기간 확대 (2013→2005 기점) — P0

**가설**: 표본이 클수록 좋다 (2017–2018만 0.611 vs 2013–2018 0.633 — 단 이 두 수치는 NUM/면적 포함 계보라 방향 근거로만 쓴다). **방법**: train 2005–2018, test 고정. **접근성 피처는 제외(LOC2)로 확정** — `asof.py`에 노선 개통일 처리가 없음이 확인돼 있어(§196-199 주석) 2005년 개업 점포에 미래 역이 새는 분기가 반드시 걸린다. 비교는 LOC2끼리: LOC2(2005–2018) vs LOC2(2013–2018), 동일 홀드아웃.

**채택 규칙(모호성 제거)**: E1이 이기면 "확장 기간 + 접근성 포기"와 "현행 기간 + 접근성 유지(LOC3)" 중 하나를 골라야 한다 — **내부 검증에서 LOC2(2005–2018) vs LOC3(2013–2018)을 직접 비교**해 우세 쪽을 Stage 2의 확정 데이터·세트로 삼고, 채택 시 전 후속 단계(E-M·E-A·precompute·헤드라인)가 그 세트로 전환되며 앵커를 재산출한다. **성공**: LOC2끼리 비교에서 AUC +0.005 이상 그리고 상위10% 실측 하락 없음. **기각 시**: "2013 이전 확대는 이득 없음(분포 이동)"으로 기록하고 LOC3 유지.

## E2. 승계(양도양수) 제외 라벨 재학습 — P0

**가설**: 승계 추정분(제외 시 생존율 +1.87%p)은 라벨 노이즈. **방법**: 라벨 재생성 → 동일 split 재학습. **제외 = 행 삭제**(`cohort.py exclude_succession`과 동일 — `succession_suspect` 32,237행 드롭. 생존자 재라벨이 아니다). 평가는 2×2(구/신라벨 × 구/신모델) — 신라벨 위 비교만 유효, 베이스라인 동반 재계산. **성공**: (신모델 − prior_surv) AUC 격차 ≥ 현재 0.0350 그리고 십분위 단조 유지. **기각 시**: "재학습해도 결론 불변"으로 한계 §5를 강화.

**E1·E2 동시 채택 시**: 각각 독립 판정 후, 결합 조건(확대 기간 + 신라벨)으로 **확인 1회**(프로브 gbm, 홀드아웃 1회)를 더 돌려 그 결과로 Stage 2의 확정 데이터를 정한다 — 개별 통과 둘이 결합 개선을 보장하지 않는다.

## E3. horizon 1년 / 5년 — P1 (UI 직결)

**가설**: 1·5년 라벨로 생존곡선의 실측 앵커 확장. **방법**: `survive_1y/5y`, 분모는 관측 가능 원칙 유지. 1년: test 2019–2024(표본 최대). 5년: test 2019–2021 상반기까지(표본 얇으면 5분위). **성공**: 각 horizon에서 모델 > prior_surv, 등급별 실측 단조. 3년 등급과 Spearman ρ ≥ 0.8이면 UI는 "등급 하나 + horizon별 곡선"으로 단순화. **기각 시**: 해당 horizon은 모델 없이 실측 코호트 곡선만 제공. `score_meta` 확장이므로 레인 B 사전 통보.

## E4. 버스 접근성 — P1.5 (채택 시 G4에 편입, 절제표 갱신)

**방법**: 서울 정류장 좌표(점 단위) → 최근접 거리·300m 내 수. as-of 한계(현재 정류장망)는 지하철과 동일 — 동일 잣대 심사. **성공(지하철 채택 시와 동일)**: AUC +0.002 이상 그리고 상위10% 개선 그리고 robustness 자치구 25/25 유지. **기각 시**: "지하철과 정보 중복"으로 기록.

## E5. 언급량 재현 — 두 번째 자치구 — P2 (시간 상자)

성격: 개선 실험이 아니라 **negative result의 강건성 실험**. 마포는 베이스라인 AUC 0.5452로 검증력이 약했다. **구 선정(사전 등록, 실행 가능형)**: `evaluate.load_split`을 구 단위로 돌려 25개 구의 AUC(gbm·**NUM 세트** — §6-B 파일럿과 동일 계보)를 직접 산출하고, 서울 전체 NUM AUC(0.6327) 이상인 구 중 점포 수 1위를 고른다. `robustness.py` 출력에는 구별 AUC가 없으므로 재사용 불가 — 직접 계산이다. 프로토콜·기준은 §6-B 동일(**+0.005, 단측** — `experiment_mention --min-gain 0.005`). **7/31까지 수집 미완이면 중단**하고 "마포 1회 측정, 재현은 향후 과제"로 남긴다.

## E6. 동급 상권 군집화 검증 — 권리금 리포트의 관문 (P1, 7/29~30)

`docs/goodwill-report-design.md` §4의 사전 등록 실험. 구조 변수만으로(매출·폐업률 금지 — 순환논리) 상권을 k=6~8 군집화하고 3종 검증: 실루엣 ≥0.25 · **매출 미사용 군집의 업종별 매출 분산 설명력 η² ≥0.2 (승부처)** · 부트스트랩 ARI ≥0.6. **리포트 구현은 병행한다(2026-07-27 확정)** — E6 결과는 스코프가 아니라 **벤치마크 레벨**을 결정: 통과 = 군집 벤치마크(Level 1~3), 실패/미완 = 서울 전체 업종 평균(Level 4)으로 강등 + 리포트에 명시 + negative 기록. 소유: 레인 A.

## A1·A2. 확정 분석 — UI 입력물 (P0, 각 반나절 이하)

**A1. 등급별 생존율 Wilson 95% CI.** 십분위당 n≈4,900 → CI 약 ±1.3%p 예상. 실값 산출 → `score_meta`에 추가(B 통보). UI가 "74.3% (73.0–75.5)"로 실을 근거.
**A2. 마진 민감도 표.** 마진 20/25/30% × 등급 상/중/하의 3년 기대손익 9칸. 부호가 바뀌는 칸은 UI에서 "가정에 민감" 배지 대상.

## 공간해상도 문제 — 해결 전략

문제: 수요(생활인구·사업체)는 행정동, 매출·유동은 상권 단위라 **같은 단위 안 격자들이 동점**이 되고, 격자 간 변별은 점 단위 피처만 만든다. 이걸 "해결"하는 방법은 넷이고, 하나는 금지다.

1. **쪼개지 말고 가는 원천을 늘린다 (주 전략 — 이 계획의 Tier 2·3·4가 그 실행).** 타 인허가 업종(점)·버스 정류장/승하차(점)·개별공시지가(필지)·아파트 세대수(단지)·건축물대장 연면적(필지)은 전부 격자보다 가늘어서, 배분 없이 격자 간 변별을 정당하게 만든다.
2. **배분이 필요해 보이면 보조 변수를 직접 피처로 쓴다.** "행정동 인구를 건물 연면적 가중으로 격자에 배분"(dasymetric) 대신, **그 보조 변수 자체(반경 내 주거 연면적·세대수)를 피처로** 넣는다 — 판별 정보는 동일하게 얻으면서 "격자 인구"라는 유사정밀 주장을 만들지 않는다. 배분 단계를 통째로 우회하는 것이 이 프로젝트의 원칙과 유일하게 양립하는 형태다.
3. **거친 값은 계속 "그 단위의 값"으로 태운다 (현행 유지).** 동 단위 값도 동 간 변별에는 기여하므로 모델·UI에서 버리지 않는다 — 단위 표기와 동점 처리를 지키는 조건으로.
4. **제출 후: 집계구 해상도 확보.** SGIS 집계구 경계를 확보하면 수요 축이 행정동→집계구(수백 m)로 내려온다 — `docs/api-applications.md` 라인에 추가할 것.

**금지**: IDW·커널 스무딩 등으로 행정동 값을 격자에 "문지르는" 모든 방법 — 새 정보 없이 유사정밀도만 생산하며, 순위가 실제로는 보간 가중치에 의해 결정되는 조용한 거짓이 된다.

**공통 산출 규칙**: 채택/기각 무관하게 `model-findings.md`에 절 추가. 기각도 서사 자산이다.
