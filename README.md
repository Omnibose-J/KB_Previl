# 서울 요식업 입점 위치 추천

공모전 출품작의 기술 파트. 서울 어느 지점이든 **100m 격자** 단위로 경쟁·생존·수요·비용을 조회하고, **과거 데이터로 검증된** 입지 등급을 매긴다.

**상태: 데이터 파이프라인 + 생존예측 모델 + 비용 시나리오 완료.** UI 미착수.

```
verify 8/8 · consistency 15/17 · as-of selftest PASS · ≤T 셀프테스트 PASS · 누수 가드 PASS
```

consistency 2종(`district`·`dongaccuracy`)은 `pipeline/consistency.py`의 선행 버그로 실행 자체가
안 된다 — 원인·영향 범위는 `docs/tracking/findings.md` F-A1.

---

## 한 문단 요약

서울 일반음식점 인허가 **53.5만 건**(1924~2026, 개·폐업 전체 이력)을 100m 격자에 올리고, 개업 시점의 상권 상태를 인허가 이력만으로 복원해(as-of) 3년 생존 여부를 학습했다. 학습 2005–2018 / 검증 2019–2022로 시간 분리했고, **상위 10% 등급 자리의 실측 3년 생존율은 74.9%(95% CI 73.6–76.1), 전체 평균은 61.7%**다. 여기에 실측 생존곡선을 곱해 "이 자리에서 이 임대료면 3년 뒤 얼마가 남는가"를 계산한다.

모델은 후보 6종(로지스틱·LightGBM·RandomForest·ExtraTrees·HistGB·MLP)을 **내부 검증에서 겨뤄** 고른 RandomForest다. 홀드아웃은 승자 확인에만 1회 썼다 — 후보를 홀드아웃에 여러 번 대보면 홀드아웃이 검증셋이 된다.

## 핵심 수치

| | |
|---|---|
| 인허가 이력 | 535,603건 · 좌표 보유 89.1% |
| 100m 격자 | 21,544개 (데이터가 닿는 셀) |
| 상권 내 격자 | 11,466 (53.2%) — 나머지는 매출 NULL |
| 서울 3년 생존율 | 2013년 개업 71.3% → 2019년 65.7% → 2023년 58.8% |
| 모델 (순수 입지) | RandomForest · AUC **0.6025** · 최고 베이스라인 0.5559 |
| 상위 10% 자리 | 실측 생존율 **74.9%** (73.6–76.1) · 전체 61.7% |
| 하위 10% 자리 | 실측 생존율 **45.2%** (43.9–46.6) |
| horizon | 1년 AUC 0.6525 · 3년 0.6025 · 5년 0.5966 (전부 베이스라인 우위·단조) |

**입지 위험의 가격**: 매출·비용이 완전히 같아도 상위 10% 자리는 3년 기대손익 +103만, 하위 10%는 −1,792만. 차이 1,895만원이 순수하게 생존확률에서 나온다. 단 이 값은 마진 가정에 더 민감하다 — 마진 20%면 세 등급 모두 적자, 30%면 세 등급 모두 흑자다(`model.ui_inputs`).

**타깃이 분명하다**: 작은 가게일수록 입지가 중요하다. 25㎡ 미만은 상위/하위 격차가 **31.1%p**인데 90㎡ 이상은 14.2%p다. **자본이 적을수록 이 서비스가 더 필요하다.**

## 실행

```bash
python -m pipeline.run --all                  # 수집 → 정규화 → 격자 → 검증
python -m model.recommend --uptae 한식 --top 10        # 입지 추천
python -m model.economics --uptae-cd CS100001 --rent 300 --upfront 8000
python -m pipeline.query --lon 127.0276 --lat 37.4979  # 좌표로 격자 조회
```

검증:
```bash
python -m pipeline.verify        # 적재 8종
python -m pipeline.consistency   # 논리 정합성 17종
python -m model.test_leakage     # 누수 가드 RED→GREEN
python -m model.asof --selftest-cut          # 신규 피처: T 이후 행을 지워도 값 불변
python -m model.backtest --model rf --features DEPLOY     # 십분위 실측 생존율
python -m model.robustness --model rf --features DEPLOY   # 상식 규칙·연도·업태·지역
python -m model.stratified       # 면적 통제 후 입지 효과
python -m model.tournament       # E-M 모델 토너먼트
python -m model.ablation_run     # E-A 피처군 절제표
```

`.env`에 키가 필요하다(커밋 금지). 수집분은 `pipeline/cache/`에 캐시되어 재실행 시 API를 다시 부르지 않는다.

## 알아야 할 다섯 가지

### 1. 좌표계는 문서가 아니라 실측으로 정했다
인허가는 **EPSG:5174**, 서울 상권은 **EPSG:5181**. 서로 다르다.

후보 좌표계들은 원점을 공유하고 datum만 달라, 틀린 걸 골라도 점이 서울 안에 그럴듯하게 떨어진다. 실제로 처음 EPSG:2097로 가정했고 **내부 검증 14/14가 통과하는 상태에서 모든 점포가 1~2 격자 밀려 있었다.** 역지오코딩으로 각 레코드의 주소와 대조해서야 잡혔다. 좌표계를 바꾸려면 `probe/p8_crs.py`부터 돌릴 것.

### 2. 데이터가 없으면 NULL이지 0이 아니다
상권 밖 격자는 매출·유동인구가 NULL이다. 0을 넣으면 그 자리가 "최악의 입지"로 랭크돼 추천이 조용히 거짓이 된다. `verify nullzero`와 `consistency nullnotzero`가 이걸 지킨다.

### 3. 거친 데이터를 격자로 배분하지 않는다
행정동 인구를 격자에 나눠 담으면 산과 하천에도 인구가 배정된다. 거친 값은 **"이 격자가 속한 단위의 값"**으로 표기해 붙이고, 같은 행정동 격자들은 그 피처에서 동점이 된다. **격자 간 순위는 점 단위 피처만이 결정한다.**

### 4. 생존율의 분모는 관측 가능한 부분이다
`survive_Ny = 1 − (N년 내 폐업) / (개업 후 N년이 이미 지난 점포)`. 2025-11 개업 점포는 3년 테스트를 못 치렀으므로 분자·분모 어디에도 안 들어간다. **"폐업한 가게 중 N년 못 버틴 비율"과 혼동하지 말 것** — 그건 실패에 조건부라 예측에 못 쓴다.

### 5. 점포 속성과 입지를 섞지 않는다
면적은 단일 최강 예측자다(면적만으로 AUC 0.6221, 25㎡ 44.8% ↔ 90㎡+ 74.4%). 절제표에서도 면적군을 빼면 ΔAUC가 +0.0445로 어느 입지 피처군보다 크다(§7 G6). 하지만 **점포 속성이지 입지가 아니고**, 추천에서는 사용자가 정하므로 모든 후보에 같은 값이 들어간다. 순위·보정 모두 면적을 뺀 모델을 쓴다. 층 정보도 마찬가지(지하 59.8% / 1층 66.2% / 2층 69.9%).

## 정직하게 남겨둔 것

- **비정형은 기여하지 않았다.** 검색 트렌드(지역 단위)와 점포 언급량(점 단위) 두 방식 모두 측정했고 둘 다 개선이 없었다. "결합했다"고 주장하지 않고 "측정했고 아니었다"고 쓴다.
- **인허가 이력 파생 피처는 포화**다. 파생 7개 추가 ΔAUC 0.0000에 이어, 다른 메커니즘(공실 회전·체인 비중·격자 나이 등 8개)을 새로 만들어도 홀드아웃 기여를 판별할 수 없었다.
- **휴게음식점(카페·패스트푸드)을 넣어도 안 올랐다.** 경쟁 피처가 일반음식점만 세고 있어 카페가 통째로 안 보인다는 지적은 옳았고 데이터도 채웠지만(14.7만 건), 번들 홀드아웃 ΔAUC는 +0.0006으로 CI가 0을 포함한다.
- **지하철 접근성의 기여는 판별 불가**다. 이전에 적었던 "+0.0025"는 신뢰구간 없는 단일 적합 차이였고, 짝지은 부트스트랩으로 다시 재니 CI가 0을 품는다(§7 G4).
- **상위 10% 자리에서도 약 25%가 3년 내 폐업**하고, 하위 10%에서도 45.2%가 살아남는다. 입지는 일부일 뿐이다.
- **AUC 0.60은 무작위보다 나은 수준**이지 "잘 맞힌다"가 아니다.
- **동급 상권 군집화(E6)는 실패했다.** 구조 변수만으로 만든 군집이 업종 내 점포당 매출 분산의 13%만 설명한다(요구 20%). 권리금 리포트의 벤치마크는 서울 전체 업종 평균(Level 4)으로 강등됐다.
- 미확보: 공정위 창업비용(승인 확인 필요) · R-ONE 임대료(키 필요) · VWORLD 물리입지(미승인) · 집계구 경계(오픈API 미제공)
