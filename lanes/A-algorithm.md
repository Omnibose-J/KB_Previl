## 알아야 할 제약 — 어기면 결과가 조용히 거짓이 된다

1. **as-of 원칙.** 피처는 개업 시점 이전 정보만. 새 피처를 넣을 때 `model/asof.py`의 `FEATURES`에 관측 시점 근거를 반드시 적고, `python -m model.test_leakage`로 RED→GREEN 확인.
2. **면적·층은 순위에서 제외.** 점포 속성이지 입지가 아니다. 면적만으로 AUC 0.6227이 나오므로 섞으면 "자본력 예측기"가 된다. 순위는 `LOC` 계열 피처셋으로.
3. **베이스라인을 약화시키지 않는다.** `prior_surv`(학습 없이 그 자리 과거 생존율)를 못 이기면 모델은 무가치하다.
4. **개선이 없으면 없다고 기록한다.** 임계·split·지표를 바꿔 통과시키지 않는다. 이미 negative result 2건이 문서에 남아 있다.

## 시도했고 안 된 것 — 반복하지 말 것

| 시도 | 결과 |
|---|---|
| 인허가 파생 피처 7개 추가 (수요군 경쟁·영업연수·엔트로피·폐업가속) | **AUC 변화 0.0000.** 중요도 상위에 오르지만 정보 중복 |
| 네이버 검색 트렌드 (행정동 단위) | logit −0.0004 / gbm +0.0014 |
| 점포별 블로그 언급량 (점 단위, 마포구 17,056개) | logit −0.0035 / gbm −0.0125 |
| Tier1 인허가 재파생 8개 (공실 회전·체인 비중·격자 나이·업태 전환 등) | 내부검증은 전부 양수였으나 번들 홀드아웃 ΔAUC +0.0006, CI∋0 |
| Tier2 휴게음식점 5개 (카페·패스트푸드 밀도·동학, 146,507건 신규 수집) | 〃 (같은 번들에 포함) |
| Tier3 지하철 승하차 (역 단위 월별, 2015-01~) | 부표 ΔAUC +0.0004 [−0.0005, +0.0013] · 커버리지로 편입 불가 |
| E6 동급 상권 군집화 | 실루엣 0.1175 · η² 0.1327 (요구 0.25 / 0.20) — 실패 |

**결론: 인허가 이력 파생은 포화이고, 새 외부 원천도 아직 이걸 못 깼다.** 지하철 접근성의 "+0.0025"는 CI 없는 단일 적합 차이였고, 짝지은 부트스트랩으로는 판별 불가(§7 G4). 실제로 이긴 것은 **학습 기간 확대(E1)와 모델 교체(E-M)** 두 가지다.
